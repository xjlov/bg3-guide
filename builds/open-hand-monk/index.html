散打武僧 Build

酒馆斗殴者 + 力量灵药 + 盗贼双附赠 = 一回合最多 10次徒手攻击，全游戏最高单体输出。

定位​

维度评价说明
输出⭐⭐⭐⭐⭐全游最高DPS
生存⭐⭐⭐AC中等+反射闪避+拨挡飞弹
机动⭐⭐⭐⭐⭐最快移速+附赠疾走+水面行走
控场⭐⭐⭐⭐震慑拳·推倒·推飞·缴械
友好度⭐⭐⭐需理解气点管理和灵药系统

种族​

种族原因推荐
木精灵/木半精灵+1.5m移速；潜行熟练⭐⭐⭐
吉斯洋基人免费迷踪步(Lv5)；跳跃强化；中甲熟练⭐⭐⭐
半兽人暴击+1骰；濒死回1血⭐⭐
灰矮人免费变巨术(1D4)；每战一次隐身⭐⭐

属性(27点购)​

STRDEXCONINTWISCHA
17(+2)→191415(+1)→168128

4级酒馆斗殴者 STR+1→20。喝山丘巨人力量灵药→STR 21(第一章)，云巨人→STR 27(第三章)。

完整12级拆分​

Lv.1 武僧1​

  • 无甲防御(AC=10+DEX+WIS)
  • 灵巧打击(D4徒手)；附赠徒手攻击
  • 疾风连击(1气=附赠2拳)
  • 气点×2
  • 玩法： 还没酒馆斗殴者，靠敏捷打。立即找山丘巨人力量灵药。

Lv.2 武僧2​

  • 无甲移动(+3m)
  • 坚强防御(1气=附赠回避)；疾走(1气=附赠疾走)
  • 气点×2
  • 玩法： 气点省着用。坚强防御保命。

Lv.3 武僧3→散打宗​

  • 拨挡飞弹(反应减远程伤1D10+DEX+3)
  • 徒手D4→D6
  • 疾风连击可附加：推倒(倒地方便全队优势)、推飞(悬崖秒杀)、缴械
  • 玩法： 控场起点。推倒>全部后续攻击优势。

Lv.4 武僧4 ⭐专长​

  • 轻身坠(免疫坠落伤害)
  • 专长：酒馆斗殴者 → STR+1(→20)，徒手/投掷命中和伤害额外+STR调整值
  • 玩法： 从此喝山丘巨人力量灵药(STR 21)。命中+10起，伤害+10起。茶室埃塞尔婶婶、地精营地、幽暗地域商人有卖灵药或原料。

Lv.5 武僧5​

  • 额外攻击(每回合2次动作攻击)
  • 震慑拳(DC=8+熟练+WIS，命中后目标跳过整回合+后续全队优势)
  • 徒手D6
  • 玩法： 震慑拳=游戏最强单控。先手震慑Boss=直接废一回合。

Lv.6 武僧6​

  • 徒手→魔法武器(穿透非魔法免疫)
  • 元素打击：徒手附加1D4+WIS 暗蚀/心灵/光耀(三选一切换)
  • 无甲移动→+4.5m
  • 完整身心：每长休1次→3回合额外附赠+气点回复
  • 气点×6
  • 玩法： 完整身心=爆发开关。Boss战开。

Lv.7 盗贼1​

  • 偷袭1D6；专精×2(巧手+察觉)
  • 为什么兼职： 盗贼3=快手=第二个附赠。武僧的附赠=疾风连击(2拳)。双附赠→一回合6拳。

Lv.8 盗贼2​

  • 灵巧动作(附赠疾走/撤离/隐匿)
  • 偷袭1D6
  • 玩法： 附赠疾走+无甲移动=全游最快。任何敌人都追不上。

Lv.9 盗贼3→盗贼​

  • 快手：第二个附赠动作
  • 偷袭2D6
  • 核心突破： 动作攻击×2 + 疾风连击×2(各2拳) = 每回合6次徒手攻击。完整身心=最多10次。

Lv.10 武僧7​

  • 反射闪避(敏捷豁免成功=0伤害，失败=半伤)
  • 心如止水(魅惑/恐惧自动解除)
  • 玩法： 反射闪避=几乎不被法术致死。

Lv.11 武僧8 ⭐专长​

  • 专长：警觉(+5先攻/免疫突袭) 或 属性提升(WIS+2→14)
  • 先手=震慑拳=敌人跳回合。先手>2点WIS。

Lv.12 武僧9​

  • 徒手D6→D8
  • 气之共鸣(标记+引爆=AoE力场)；高级无甲移动(水面行走)
  • 气点×10

战斗循环​

标准回合： 动作攻击×2 + 疾风连击(附赠1)×2拳 + 疾风连击(附赠2)×2拳 = 6拳

爆发回合(完整身心)： 开完整身心→动作×2 + 附赠×3疾风连击 + 加速术→10拳

单拳伤害(毕业)： D8基础 + D10力场(手套) + STR调整×2(酒馆) + D4+WIS(元素) + WIS(靴子) + 3(戒指) ≈ 25-40

每长休和角色升级刷新商人。Act1去茶室囤山丘巨人灵药。

荣誉模式​

  • 酒馆斗殴者伤害加值不翻倍
  • 完整身心窗口缩短
  • 单存档，灵药只用在关键战
