投掷野蛮人 (Throw Barbarian)

构建概览​

投掷野蛮人是《博德之门3》Patch 7中最适合新手的远程物理构建之一。采用**野蛮人5(狂战士) / 游荡者3(盗贼) / 战士4(奥法骑士)**的三重兼职，本构建拥有全游戏最稳定的每回合输出能力和最强的单体控制（倒地）。

核心标签：远程投掷、酒馆殴斗者、倒地控制、新手友好、高容错

构建优势​

优势说明
操作极其简单每回合就是"投掷、投掷、投掷、投掷"——不需要考虑站位、弹药、资源管理
伤害极其稳定酒馆殴斗者专长让力量加值翻倍应用于投掷命中和伤害，投掷命中率极高
自带硬控狂战士的狂怒投掷让目标进行力量豁免，失败则倒地——为全队近战提供攻击优势
多目标打击尼鲁纳(Nyrulna)的范围雷电爆炸让每次投掷都变成小型AoE
高生存力野蛮人的d12生命骰+物理伤害抗性(狂暴)+危险感知(敏捷豁免优势)
装备获取简单核心装备(回旋长矛)在第一章早期即可获得，且可一直用到第三章

构建劣势​

劣势说明
狂暴资源有限每天仅3-4次狂暴，长休之间需要管理使用节奏
投掷路径受限投掷需要清晰的弹道——天花板、障碍物会阻挡投掷
近战弱势投掷时近战敌人获得攻击优势(远程攻击特性)，虽然野蛮人物理抗性可以承受
对高力量敌人控制减弱狂怒投掷的倒地DC基于力量，对高力量boss成功率降低
武器绑定限制奥法骑士的武器绑定仅能绑定1把武器(但有回旋长矛则不需要绑定)

核心机制深度解析​

机制一：酒馆殴斗者 (Tavern Brawler)​

这是本构建的绝对核心专长，也是构建存在的前提：

效果说明
力量+1将奇数力量变成偶数
徒手和投掷攻击命中+力量调整值×2正常是+力量调整值×1。现在力量18(+4)时投掷攻击获得+8命中
徒手和投掷伤害+力量调整值×2正常是+力量调整值×1。现在力量18(+4)时投掷伤害获得+8额外伤害
徒手攻击伤害骰变为1d4对本构建不重要

酒馆殴斗者的数值影响：

力量值正常投掷命中酒馆命中正常投掷伤害酒馆伤害
17(+3)+3(力量)+熟练+6(力量×2)+熟练+3+6
18(+4)+4+熟练+8+熟练+4+8
20(+5)+5+熟练+10+熟练+5+10

在12级时(熟练+4)，力量20的酒馆殴斗者投掷攻击加值 = 4(熟练) + 10(力量×2) + 3(武器加值) = +17！几乎不会miss。

机制二：狂怒投掷 (Frenzied Throw)​

狂战士子职在狂暴状态下获得的核心能力：

  • 狂怒(Frenzy)：狂暴升级为狂怒
  • 狂怒打击(Frenzied Strike)：附赠动作额外近战攻击（我们不使用——这是投掷build）
  • 狂怒投掷(Frenzied Throw)：🔑 附赠动作进行投掷攻击，目标需进行力量豁免(DC = 8 + 熟练加值 + 力量调整值)，失败则倒地(Prone)

关键规则：

  • 狂怒投掷必须消耗附赠动作——这就是为什么需要盗贼3(额外附赠动作)
  • 每次使用狂怒投掷，你获得1层"狂怒疲劳"(Frenzied Strain)，每层-1攻击掷骰。但这个惩罚在BG3中已被大幅降低
  • 狂怒投掷可以使用任何可投掷物品——包括你绑定的武器

机制三：额外附赠动作 (Fast Hands)​

盗贼3级的快速之手提供第二个附赠动作：

标准狂战士(无盗贼)：
├── 攻击动作：2次投掷(额外攻击)
├── 附赠动作：1次狂怒投掷
└── 总计：3次投掷/回合

狂战士+盗贼(本构建)：
├── 攻击动作：2次投掷(额外攻击)
├── 附赠动作1：1次狂怒投掷
├── 附赠动作2：1次狂怒投掷
└── 总计：4次投掷/回合 🔥

机制四：武器绑定 (Weapon Bond)​

奥法骑士3级的武器绑定：

  • 绑定1把武器(动作)
  • 绑定的武器获得"投掷后自动返回手中"特性
  • 绑定持续到长休
  • 武器不能被缴械

为什么需要这个？ 回旋长矛(第一章)和尼鲁纳(第三章)自带投掷返回特性，似乎不需要绑定？答案是：

  1. 备用：如果回旋长矛/尼鲁纳因故无法使用(如被缴械)，你有绑定其他武器的能力
  2. 某些特殊投掷武器不自带返回（如闪电标枪）——绑定让它们也能返回
  3. 如果你选择的武器路径不同——绑定提供了灵活性

种族选择​

主推：金矮人 (Gold Dwarf)​

种族特性效果价值评估
矮人韧性(Dwarven Resilience)对抗毒素的豁免优势，毒素伤害抗性⭐⭐⭐⭐ 第二章大量毒素敌人
矮人体质+2初始体质可轻松达到16+⭐⭐⭐
矮人战斗训练战斧/手斧/轻锤/战锤熟练⭐⭐ 投掷不需要近战武器熟练
黑暗视觉12m⭐⭐⭐⭐
基础移速7.5m比标准慢1.5m⭐⭐ 不影响投掷射程

金矮人的优势在于生存——毒素抗性在第二章面对蛛化精灵和毒素陷阱时非常有用。矮人体质+2让初始属性分配更从容。

备选：木精灵 (Wood Elf)​

种族特性效果价值评估
移动速度10.5m比标准快1.5m，比矮人快3m⭐⭐⭐⭐ 更好的投掷位置
精灵武器训练长剑/短剑/长弓/短弓熟练⭐⭐
黑暗视觉12m⭐⭐⭐⭐
魅惑优势+睡眠免疫防御特性⭐⭐⭐

木精灵的移动速度让你更容易找到最佳投掷位置（高处+无遮挡弹道）。如果你更重视机动性而不是生存力，木精灵是更好的选择。

其他可选种族​

种族亮点权衡
半兽人 (Half-Orc)不屈(1HP存活)、重击+1骰但这些对投掷build价值有限——投掷很少重击
吉斯洋基 (Githyanki)免费迷踪步、中甲熟练、星界知识优秀的机动性和技能灵活性
人类 (Human)盾牌熟练+全技能但野蛮人已经有盾牌熟练

属性分配​

27点购点方案​

属性购点种族加值最终值调整值说明
力量 (STR)17-17+3🔑🔑 绝对主属性——投掷命中和伤害，酒馆殴斗者翻倍加成
敏捷 (DEX)14-14+2中甲AC上限(+2)、先攻(+2)、敏捷豁免(危险感知优势)
体质 (CON)16-16+3🔑 野蛮人无甲防御(+3AC)、HP(每级+3)、狂暴持续时间
智力 (INT)8-8-1无用
感知 (WIS)10-10+0感知豁免(不可更低)
魅力 (CHA)8-8-1无用（让吟游诗人队友去对话）
注意

本构建不使用种族属性加值——因为BG3中所有种族的属性加值已经改为自由分配(+2/+1任意属性)。如果你使用金矮人，体质+2的种族加值同样可以自由分配到力量上。

属性成长路线​

等级属性变化力量体质
1级初始17 (+3)16 (+3)
4级酒馆殴斗者 STR+118 (+4)16 (+3)
9级ASI 力量+220 (+5)16 (+3)
12级警觉 (无属性提升)20 (+5)16 (+3)

替代方案：使用力量药水/护符​

如果你使用山丘巨人力量药水(Hill Giant Strength Elixir)（力量固定21）或蛮力护符(Amulet of Hill Giant Strength)（力量固定23），则可以完全放弃力量购点，将属性投资到敏捷和体质上：

属性购点(护符方案)说明
STR8(固定23)用护符/药水
DEX16+3先攻+3AC=更高先攻
CON17配合体质+1达到18(+4)
INT/WIS/CHA8/10/8不变

此方案的代价是占用护符槽(不能带其他项链)或需要持续购买/制作力量药水。

专长选择​

专长详细分析​

等级专长效果选择理由
野蛮人4酒馆殴斗者 (Tavern Brawler)力量+1(17→18)，徒手/投掷攻击力和伤害+力量调整值×2🔑 **本构建存在的前提！**投掷命中+8(而非+4)，投掷伤害+8(而非+4)。没有这个专长，投掷build不成立
战士4(总等级9)ASI 力量+2力量18→20主属性封顶，+1命中/+1伤害(+酒馆翻倍=+2/+2)
游荡者/战士(总等级12)警觉 (Alert)先攻+5，免疫突袭先出手=先用狂怒投掷倒地敌人=队友的攻击全部优势。野蛮人的先攻通常不高(敏捷仅14)，警觉补足这一点

未选择的重要专长​

专长为何不选
巨武器大师 (GWM)本构建是投掷build，不使用近战双手武器
神射手 (Sharpshooter)投掷不算远程武器攻击(算投掷)，不触发神射手
凶蛮打手 (Savage Attacker)投掷伤害骰较小(武器1d6-1d10+各种附加)，重投一次的价值不高
双重持用者 (Dual Wielder)投掷需要空手或单手武器——副手通常是空的(准备接返回的武器)

完整升级路线：逐级详细拆解​

第1级：野蛮人1​

职业：野蛮人1
生命骰：1d12 + 3(体质) = 15 HP
熟练加值：+2

获得的能力：

能力类型详细说明
狂暴 (Rage)职业特性附赠动作启动，持续10回合(专注维持)。效果：力量武器攻击伤害+2，力量检定和豁免优势，物理伤害(穿刺/挥砍/钝击)抗性。但狂暴期间不能施法和维持专注。2次/长休
无甲防御 (Unarmored Defense)职业特性不穿甲时，AC = 10 + 敏捷调整值 + 体质调整值 = 10 + 2 + 3 = 15 AC

战斗策略(1级)：

  • 目前还没有投掷核心能力，以近战为主
  • 使用任意近战武器+盾牌 (AC 15+2=17)
  • 狂暴后获得物理抗性，可以放心上前排
  • 也可以捡地上物品投掷——任何东西都能投！敌人、箱子、桶都可以

装备目标：

  • 任意单手近战武器+盾牌
  • 尽快找到第一把可投掷的武器

第2级：野蛮人2​

职业：野蛮人2
生命骰：2d12 + 6 = 约26 HP
熟练加值：+2

获得的能力：

能力类型详细说明
危险感知 (Danger Sense)职业特性🔑 对抗可见陷阱、法术和效果的敏捷豁免获得优势。对野蛮人来说极其重要——火球术和闪电束的敏捷豁免现在有优势了
鲁莽攻击 (Reckless Attack)职业特性🔑 主动攻击时获得优势，但敌人对你的攻击也获得优势。**对投掷同样有效！**虽然投掷通常从远处发动(不受敌人近战优势影响)，但鲁莽攻击让你即使处于劣势情况下也能保证命中率

鲁莽攻击的战术价值：

  • 投掷build通常在远处——敌人对你的攻击优势可能无实际影响(他们打不到远程的你)
  • 任何时候需要命中保证时开启鲁莽攻击
  • 配合酒馆殴斗者的高命中，鲁莽攻击让miss几乎不可能

第3级：野蛮人3（狂战士子职）​

职业：野蛮人3（狂战士）
生命骰：3d12 + 9 = 约39 HP
熟练加值：+2
狂暴次数：3次/长休

获得的能力：

能力类型详细说明
狂怒 (Frenzy)子职业狂暴升级为"狂怒"。额外狂暴伤害从+2变为更强大的效果
狂怒打击 (Frenzied Strike)子职业附赠动作额外近战攻击（不使用——投掷build用不到）
狂怒投掷 (Frenzied Throw)子职⭐⭐⭐ 核心能力解锁！狂暴状态下，附赠动作投掷物品/武器，目标需进行力量豁免(DC = 8 + 熟练加值 + 力量调整值)，失败则倒地(Prone)

狂怒投掷详解：

倒地状态(Prone)效果：
├── 近战攻击对该目标获得优势
├── 目标移动速度减半
├── 目标无法站立(需消耗一半移速起身)
├── 远程攻击对倒地目标获得劣势（但投掷不算远程攻击！）
└── 力量豁免DC在3级：8 + 2(熟练) + 3(力量) = DC 13

疲劳机制(狂怒疲劳-Frenzied Strain)：
每次使用狂怒投掷后获得1层疲劳，每层-1攻击掷骰。
在BG3实际实现中，这个惩罚被大幅降低或不存在。

战斗策略(3-4级)：

  • 第一回合：附赠动作启动狂怒，攻击动作投掷2次（攻击+额外攻击还没到5级，目前只有1次攻击）
  • 狂暴后每回合：攻击动作1次投掷 + 附赠动作1次狂怒投掷 = 2次投掷/回合
  • 狂怒投掷优先针对高价值目标(施法者/远程)——倒地后队友近战收割
  • 如果还没拿到回旋长矛，先捡地上的矛/标枪/手斧投掷

装备目标：

  • 🔑 立即前往哥布林营地购买回旋长矛(Returning Pike)！
  • 回旋长矛：地精营地商人格拉特·布尔特(Grat the Trader)出售，价格约200-300金币
  • 回旋长矛属性：+1矛，投掷后自动返回手中（无需任何绑定！）
  • 这是第一章早期最强投掷武器，可从3级用到第三章

第4级：野蛮人4（酒馆殴斗者）​

职业：野蛮人4
生命骰：4d12 + 12 = 约53 HP
熟练加值：+2

获得的能力：

能力类型详细说明
专长：酒馆殴斗者 (Tavern Brawler)专长🔑 构建质变。力量17→18 (+4)。投掷攻击和伤害获得力量调整值×2(即+8命中、+8伤害)

酒馆殴斗者前后对比：

阶段投掷攻击加值投掷伤害(回旋长矛)
4级前(无酒馆)+2(熟练)+3(力量)+1(武器)=+61d10+1+3(力量) = 5.5+1+3 = 9.5
4级后(有酒馆)+2(熟练)+8(力量×2)+1(武器)=+111d10+1+8(力量×2) = 5.5+1+8 = 14.5
提升幅度+5命中 🔥+5伤害/次(约52%提升)

战斗策略(4级)：

  • 命中率巨幅提升——几乎不用考虑miss
  • 继续使用回旋长矛投掷
  • 狂怒投掷的倒地DC也提高了(力量18→DC 8+2+4=DC 14)
  • 如果还没有回旋长矛，现在是最紧迫的目标

第5级：野蛮人5（额外攻击+快速移动）​

职业：野蛮人5
生命骰：5d12 + 15 = 约67 HP
熟练加值：+3（升级！）
狂暴次数：3次/长休

获得的能力：

能力类型详细说明
额外攻击 (Extra Attack)职业特性🔑 攻击动作变为2次攻击。配合附赠狂怒投掷=每次攻击动作2次投掷+附赠1次投掷=3次投掷/回合
快速移动 (Fast Movement)职业特性不穿重甲时移动速度+3m。基础移动7.5m→10.5m(矮人)，或10.5m→13.5m(木精灵)

5级战斗循环：

第一回合：
├── 附赠动作：启动狂暴
├── 攻击动作：2次投掷（回旋长矛）
└── 总计：2次投掷 + 倒地控制

后续回合(狂暴已启动)：
├── 攻击动作：2次投掷（回旋长矛）
├── 附赠动作：1次狂怒投掷（伤害+倒地）
└── 总计：3次投掷/回合 + 每次狂怒投掷附带倒地控制

为什么5级后选择兼职而非继续野蛮人？

野蛮人6级获得：子职特性(狂战士获得"无意识狂暴"——狂暴期间魅惑/恐惧免疫)。有用，但不如盗贼的额外附赠动作那么质变。 野蛮人7级获得：先攻优势(不差，但警觉专长更好)。 因此，5级后立即转兼职是最优选择。

第6级：游荡者1​

  • 察觉(Perception)：熟练+3×2=+6，配合感知10(+0)=+6察觉。发现隐藏陷阱、暗门、埋伏——全队受益

战士提供三个关键价值：

  3. 奥法骑士子职（再下一级——武器绑定）

战士的兼职顺序放在了游荡者3之后，因为额外附赠动作(每回合多1次狂怒投掷)比动作如潮(每短休一次爆发)对持续输出的提升更大。

  1. 非狂暴的战斗
  2. 战斗前的buff(护盾术是反应——如果在狂暴前施放可能有效)
  3. 探索/社交场景

├── 附赠动作2：狂怒投掷（目标C） → 力量豁免DC 16(力量20时) → 失败则倒地
└── 总计：3次投掷（第一回合略少，因为附赠用于启动狂暴）

阶段3：后续回合（狂暴已启动）
├── 攻击动作：投掷×2 → 回旋长矛自动返回
│   每次投掷伤害：
│   1d10+3(武器) + 10(酒馆) + 1d4(投掷戒指) + 1d4(库希戈手套) + 2(腐蚀戒指) 
│   = 5.5+3+10+2.5+2.5+2 = 25.5 平均伤害/次
│
├── 附赠动作1：狂怒投掷 → 伤害同上 + 倒地控制
│   力量豁免DC = 8 + 4(熟练) + 5(力量) = DC 17
│
├── 附赠动作2：狂怒投掷 → 伤害同上 + 倒地控制
│
└── 总计：4次投掷/回合
    总伤害：4 × 25.5 = 102 伤害/回合
    总控制：2次倒地尝试(DC 17)

爆发回合（动作如潮）​

执行顺序：
├── 附赠动作1：狂怒投掷（目标A → 倒地DC 17）
├── 攻击动作：投掷×2（目标A/B）
├── ⚡ 动作如潮：投掷×2（目标A/B）
├── 附赠动作2：狂怒投掷（目标C → 倒地DC 17）
└── 总计：6次投掷
    总伤害：6 × 25.5 = 153 伤害/爆发回合
    总控制：2次倒地尝试（狂怒投掷只能附赠用）

针对不同敌人类型​

敌人类型策略调整
高力量敌人倒地DC难度大——优先用普通投掷输出，狂怒投掷视为"赌一把"控制
飞行敌人投掷弹道可能受阻——使用迷踪步传送到高处再投掷
远程敌人群用尼鲁纳的AoE爆炸同时伤害多个远程敌人；狂怒投掷逐个倒地
近战敌人群保持距离——虽然有物理抗性，但被多人围攻还是会痛
构装体/元素这些敌人通常免疫倒地——所以狂怒投掷的控制无效。专注用普通投掷输出，或改用常规攻击动作

常见问题与误区​

误区：投掷算远程攻击

投掷在BG3中属于远程武器攻击的一个子类，但很多"远程武器攻击"的加成对投掷不适用。具体来说：

  • 有效的加成：酒馆殴斗者、投掷戒指(+1d4投掷)、库希戈手套(+1d4投掷)、狂战士角盔(+2伤害)
  • 无效的加成：神射手(-5/+10)、箭术战斗风格(+2命中)、弩专家
  • 投掷使用力量而非敏捷作为攻击属性(即使投掷的是精巧武器)
狂暴次数管理

3次狂暴/长休意味着一场大型地城最多打3场大型狂暴战斗。在非狂暴战斗中：

  • 你依然可以投掷（缺少+2狂暴伤害、缺少狂怒投掷的倒地控制）——输出降低约15-20%
  • 保留狂暴给boss战或强力敌人群
  • 利用休憩之歌(如果有诗人队友)短休+额外短休来最大化作战续航
投掷技巧
  1. 高处投掷：从高处往下投掷获得+2命中加成
  2. 弹道检查：投掷前确认目标没有障碍物遮挡(天花板、柱子等)
  3. 物品投掷：即使没有近战武器，你也可以投掷环境物品(桶、箱子、甚至敌人！)
  4. 力量豁免计算：狂怒投掷的倒地DC = 8 + 熟练加值 + 力量调整值。在12级时为DC 17，对大多数敌人成功率约60-75%

总结​

投掷野蛮人是BG3中最稳定、最简单、最不容易失误的物理输出构建。

核心游戏计划：

  1. 启动狂暴
  2. 攻击动作投掷2次
  3. 附赠动作狂怒投掷2次(带倒地控制)
  4. 每回合稳定4次投掷 = 100+伤害 + 2次倒地控制
  5. Boss战动作如潮 = 6次投掷

不可替代的装备(按优先级)：

  1. 回旋长矛(第一章早期) → 尼鲁纳(第三章)
  2. 投掷戒指(第一章，+1d4)
  3. 库希戈无拘手套(第一章晚期/第二章，+1d4)
  4. 腐蚀戒指(第一章晚期/第二章，+2酸性)

适合人群：

  • 新手玩家——最简单的操作，最稳定的输出
  • 不喜欢管理资源的玩家——核心循环只有"投掷、投掷、投掷"
  • 需要一个稳定前排兼输出的角色——野蛮人的生存力+d12生命骰
  • 喜欢控制但不想要复杂法术的玩家——狂怒投掷的倒地是最简单的控制方式
