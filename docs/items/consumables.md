# 消耗品全指南

合理使用消耗品是降低战斗难度的关键。许多强力消耗品只需要营地炼金术即可大量产出。

***

## 药水 (Potions)

| 名称 | 效果 | 来源 |
|------|------|------|
| **速度药水** | 3回合加速状态（额外动作、+2AC、敏捷豁免优势）；结束后1回合昏睡 | 鬣狗耳朵+盐（炼金）；商店 |
| **隐身药水** | 10回合隐身（战斗/施法中断） | 隐形菇+盐（炼金）；商店 |
| **治疗药水** | 2d4+2 治疗 | 罗勒香料+任何悬浮物（炼金） |
| **高级治疗药水** | 4d4+4 治疗 | 罗勒×2+任何灰烬（炼金） |
| **至尊治疗药水** | 10d4+20 治疗 | 罗勒×3+任何精华（炼金） |
| **巨像之力药水** | 体型变大，力量优势，额外1d4武器伤害 | 巨人指甲等（炼金） |
| **火球药水** | 投掷：6d6火焰伤害 | 炼金/掉落 |
| **动物交谈药水** | 10回合动物交谈 | 橡木（炼金） |

***

## 灵药 (Elixirs)

灵药持续到**下次长休**，但一次只能激活一个（新灵药替换旧灵药）。

| 名称 | 效果 | 推荐场景 | 来源 |
|------|------|----------|------|
| **云巨人力量灵药** | 力量设为**27** | 投掷流、力量近战 | 云巨人指甲（炼金） |
| **山丘巨人力量灵药** | 力量设为**21** | 前期力量替代 | 山丘巨人指甲（炼金） |
| **嗜血灵药** | 击杀后获得额外动作 | 多目标战斗、清杂 | 虫子×3（炼金） |
| **警觉灵药** | 先攻+5，免疫突袭 | 荣誉模式必备 | 钩子+任何精华（炼金） |
| **心灵防护灵药** | 心灵伤害抵抗 | 夺心魔战斗 | 炼金/商店 |
| **力量灵药（普通）** | 力量设为**17** | 前期 | 巨人手指（炼金） |

***

## 涂剂/毒药 (Coatings & Toxins)

涂剂和毒药可施加在武器上（附赠动作），持续10回合或直到触发。

| 名称 | 效果 | 来源 |
|------|------|------|
| **基础毒药** | 1d4 毒素伤害（DC12体质） | 炼金/掉落 |
| **卓尔毒药** | 中毒+睡眠（DC13体质） | 卓尔掉落/商店 |
| **锐锋油** | 攻击骰+3；伤害如同魔法武器 | 精致宝石（炼金） |
| **迟缓药膏** | 减速目标 | 炼金 |
| **麻痹毒药** | 麻痹目标（DC15） | 稀有炼金材料 |
| **黑暗油膏** | 目标区域内创造黑暗 | 炼金 |
| **爆裂药剂** | 命中后爆炸（AoE火焰） | 炼金 |

:::tip 涂剂使用技巧

涂剂可在战斗前提前施加，不消耗战斗中的附赠动作。每场Boss战前，给全队武器上锐锋油是最佳习惯。

:::

## 箭矢 (Arrows)

仅限弓/弩使用。

| 名称 | 效果 |
|------|------|
| **多目标箭矢** | 击中目标后弹射至附近2个敌人（最强箭矢之一） |
| **杀戮箭矢** | 额外1d6伤害 + 目标HP低于50%时可能即死 |
| **黑暗箭矢** | 目标点创造黑暗区域（无专注） |
| **雷鸣箭矢** | 击退目标 + 雷鸣伤害 |
| **火焰/冰霜/闪电箭矢** | 对应元素伤害 + 地面效果 |

***

## 卷轴 (Scrolls)

卷轴可单次无消耗施法，法术DC取决于施法者属性（或固定DC）。

| 名称 | 效果 | 备注 |
|------|------|------|
| **无敌护罩卷轴** | 6环 无敌护罩（3回合内免疫所有伤害） | 最终战神器 |
| **连锁闪电卷轴** | 6环 连锁闪电（10d8闪电伤害，4目标） | 配合湿润效果双倍伤害 |
| **任意门卷轴** | 4环 任意门（传送至可见范围任意位置） | 营救/逃脱 |
| **解离术卷轴** | 6环 解离术（10d6+40力场伤害） | 单体爆发 |
| **云雾术卷轴** | 1环 云雾术 | 遮蔽视线，前期防御 |
| **火球术卷轴** | 3环 火球术（8d6火焰AoE） | 清杂主力 |

## 批量生产建议

在营地使用**炼金术菜单**可大量制作消耗品。优先采集以下材料：

- **罗勒**：用于制作各级治疗药水
- **鬣狗耳朵 + 盐**：速度药水（制作优先级最高）
- **云巨人指甲**：终极灵药（商人可购买）
- **山丘巨人指甲**：前期力量灵药
- **隐形菇**：隐形药水（偷窃/探索必备）

:::info

商人在每次长休和角色升级后都会刷新商品，可反复购买材料。

:::
