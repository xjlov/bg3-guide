# 同伴大全

## 好感度系统

同伴对你的态度取决于**赞同/反对**值。触发对话选项时，同伴的反应会影响其对主角的评价。

### 影心

| 她赞同 | 她不赞同 |
|--------|---------|
| 尊重隐私、不过分追问 | 过度打探她的过去 |
| 帮助弱小、保护难民 | 无端残忍、出卖提夫林 |
| 给她夜兰花(第二章找到) | 逼她接受莎尔的信仰 |
| 让她在莎尔神殿自己做选择 | 替她做决定 |

**个人任务关键点：** 第二章莎尔神殿——杀暗夜之歌(变暗夜法官)还是不杀(转向塞伦涅)。推荐不杀，剧情好结局。

### 阿斯代伦

| 他赞同 | 他不赞同 |
|--------|---------|
| 支持他成为吸血鬼领主的野心 | 批评他或同情他的受害者 |
| 利用他人达成目的 | 无偿帮助他人 |
| 幽默风趣的对话 | 道德说教 |
| 让他吸你的血 | 拒绝他的请求 |

**个人任务关键点：** 第三章卡扎多尔宫殿——让他飞升(力量大增但性格变黑)或阻止(保持人性)。

### 盖尔

| 他赞同 | 他不赞同 |
|--------|---------|
| 给他魔法物品消耗(只需3件) | 拒绝给他魔法物品 |
| 支持他不自爆的路线 | 鼓励他自爆(他会真的做) |
| 智识相关的对话选项 | 轻视魔法或知识 |
| 和密斯特拉和解 | 怂恿他挑战密斯特拉 |

**个人任务关键点：** 第三章耐色瑞尔王冠——支持他归还王冠(教授路线)或成神(野心路线)。

### 莱埃泽尔

| 她赞同 | 她不赞同 |
|--------|---------|
| 尊重吉斯洋基传统 | 嘲笑她的种族或信仰 |
| 直接、不绕弯的对话 | 懦弱、回避战斗 |
| 支持她反抗弗拉基斯 | 继续效忠弗拉基斯 |
| 在养育间完成净化装置剧情 | 跳过养育间 |

**个人任务关键点：** 第一章养育间——得知弗拉基斯真相后，支持她追随俄耳甫斯(好结局)或继续效忠女王。

### 卡菈克

| 她赞同 | 她不赞同 |
|--------|---------|
| 保护平民、帮助弱者 | 滥杀无辜 |
| 给她地狱铁(第一章/第二章找达蒙) | 拒绝帮她修引擎 |
| 鼓励她活下去 | 告诉她放弃希望 |
| 直接了当的战斗方式 | 背叛盟友 |

**个人任务关键点：** 第一章+第二章找达蒙修引擎(需2块地狱铁)。第三章她面临必死选择——回阿弗纳斯或死亡。

### 威尔

| 他赞同 | 他不赞同 |
|--------|---------|
| 帮助难民、保护无辜 | 自私自利的选择 |
| 支持他摆脱米佐拉 | 鼓励他继续契约 |
| 救他的父亲(钢铁王座) | 放弃营救公爵 |
| 打破契约束缚 | 接受米佐拉的新交易 |

## 招募关键细节

### 第一章必须做的
- **影心**：序章螺壳舰别跳过她的舱体。没救也别担心，海滩上还有一次机会
- **阿斯代伦**：海滩西侧小径，别杀他
- **盖尔**：路边不稳定传送门，选"伸手"而非"离开"
- **莱埃泽尔**：提夫林笼子旁，假意帮她脱困
- **威尔**：德鲁伊林地训练场
- **卡菈克**：晋升之路河边，先听她说，别交任务给圣武士

### 明萨拉特殊招募方法
- 第一章在地精营地找到她
- **不要杀她**——在她旁边打开非致命攻击(N键)，用近战武器击晕
- 正常杀其他两首领、救哈尔辛
- 第二章在月出之塔下层监狱找到她，解救后可招募

:::warning 哈尔辛与明萨拉
正常流程无法同时拥有两人。但上述击晕明萨拉的方法可以在保有哈尔辛和提夫林的前提下，第二章招募明萨拉。
:::

:::tip 营地工具人
不常用的同伴可以留在营地当Buff工具人——让牧师放守护之链、死亡守护、援助术、庇护术后再离队，buff依然有效。
:::
