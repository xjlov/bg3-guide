## 影心好感度

| 赞同 | 反对 |
|------|------|
| 尊重隐私 | 打探她的过去 |
| 帮助难民 | 无端残忍 |
| 给她夜兰花 | 替她做决定 |
| 让她在莎尔神殿自己选择 | 逼她接受莎尔 |

**个人任务：** 第二章莎尔神殿 → 杀暗夜之歌(暗夜法官)或不杀(塞伦涅)。推荐不杀。

## 阿斯代伦好感度

| 赞同 | 反对 |
|------|------|
| 支持他成为吸血鬼领主 | 批评或同情受害者 |
| 利用他人达成目的 | 无偿帮助他人 |
| 让他吸你的血 | 拒绝他的请求 |

**个人任务：** 第三章卡扎多尔宫殿 → 让他飞升或阻止。

## 卡菈克好感度

| 赞同 | 反对 |
|------|------|
| 保护平民 | 滥杀无辜 |
| 给她地狱铁 | 拒绝修引擎 |
| 鼓励她活下去 | 背叛盟友 |

**个人任务：** 第一章+第二章找达蒙修引擎(需2块地狱铁)。

## 明萨拉特殊招募

第一章地精营地：打开非致命攻击(按N)→用近战击晕明萨拉→正常杀其他首领→救哈尔辛→第二章月出之塔下层救她招募。

:::warning
正常流程哈尔辛和明萨拉不可兼得。击晕明萨拉是唯一例外。
:::
