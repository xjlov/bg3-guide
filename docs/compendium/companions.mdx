## 明萨拉特殊招募方法

<ContentCard icon="💀" title="同时拥有哈尔辛和明萨拉">

1. 第一章在地精营地找到明萨拉，**打开非致命攻击**（按 N 键，近战武器）
2. 用近战击晕她——**不要用远程和法术**
3. 正常击杀另外两个首领（迦特和拉格兹林），救出哈尔辛
4. 第二章在月出之塔下层监狱找到被审判的明萨拉，解救可招募

:::warning
正常流程无法同时拥有哈尔辛和明萨拉。上述击晕方法是唯一保留两人的途径。
:::
