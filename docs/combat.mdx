## 动作经济

| 资源 | 每回合 | 最佳用法 |
|------|--------|---------|
| 动作 | 1次 | 攻击、施法 |
| 附赠动作 | 1次 | **每回合都有！** 跳跃、喝药、副手攻击、推击 |
| 移动 | ~9m | 可拆分使用：移动→攻击→再移动 |
| 反应 | 1次/轮 | 借机攻击、法术反制、护盾术 |

**加速术** = 额外动作（+1攻击）。**动作如潮**（战士2级）= 再+1动作。  
**嗜血灵药** = 击杀后+1动作。三个叠加 → 一回合攻击**7次**。

## 五大团队连招

| 连招 | 组合 | 效果 |
|------|------|------|
| **湿润+闪电** | 造水术/投水 + 闪电束/链闪 | 闪电伤害2倍 |
| **定身+近战** | 人类定身术 + 巨武器 | 5尺内攻击自动暴击 |
| **黑暗+魔鬼视界** | 黑暗术 + 恶魔视界 | 敌人劣势，你优势 |
| **倒地+猛击** | 绊摔打击 + 巨武器大师 | 倒地后后续攻击优势 |
| **推下悬崖** | 雷鸣波/推击 | 无视血量秒杀 |

## 环境战术

| 技巧 | 操作 |
|------|------|
| 高地打低地 | 命中+2，远程射程翻倍 |
| 油桶+火焰 | 堆叠油桶→火焰箭引爆→巨额AOE |
| 水+电 | 投水湿润→电爪/闪电箭→全屏触电 |
| 冰面 | 敌人移动可能滑倒(倒地) |
| 卡门战术 | 占据门口/窄道，敌人只能一个个进来 |
