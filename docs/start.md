# 新手上手指南

## 这是什么游戏？

**博德之门3**（Baldur's Gate 3）是 Larian Studios 开发的 CRPG，基于龙与地下城第5版规则。60-150小时流程，回合制战斗，选择影响故事。

## 操作速览

| 按键 | 功能 |
|------|------|
| F5 / F8 | 快速存档/读档 |
| Tab | 切换角色 |
| I | 背包 |
| M | 地图 |
| ~ | 高亮可交互物品 |
| Shift+空格 | 回合制模式 |

## 第一个角色选什么？

**新手推荐：战士（战斗大师）**
- 近战简单直接，不需要管理法术位
- 高AC生存能力强，动作如潮爆发高
- 等级3选「战斗大师」子职业

## 开局必做

1. 鹦鹉螺号 → 救影心（舱体里）
2. 坠机海滩 → 搜刮、找齐所有队友
3. 德鲁伊林地 → 关键任务中心
4. **经常存档！** F5是你的好朋友

## 难度选择

| 难度 | 适合 |
|------|------|
| 探索者 | 纯新手/剧情党 |
| 平衡 | 有RPG经验的玩家（推荐） |
| 战术家 | 熟悉D&D的玩家 |
| 荣誉模式 | 挑战者，单存档无法降级 |

:::warning 新手最常犯的错
- 只用1个存档 → 多存档！
- 不休息 → 长休会推进剧情
- 只练主角 → 4人队伍都要发展
- 卖传奇装备 → 先确认是否毕业装
:::
