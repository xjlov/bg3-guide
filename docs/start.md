# 纯新手上手指南

> 没玩过 D&D？没玩过 CRPG？从来没用过回合制战斗？这篇指南为你准备。

## 一、这是什么游戏？

**博德之门3**（Baldur's Gate 3，简称 BG3）是一款**角色扮演游戏（RPG）**，基于桌面游戏「龙与地下城第5版」（D&D 5E）规则。所有战斗是**回合制**，所有不确定的行动靠**投骰子**决定成败。

- 完整流程 60~150 小时，分序章 + 三大章节
- 你的选择会实实在在地改变剧情走向、队友生死、甚至游戏结局
- 队伍最多 4 人（含主角），可在营地随时切换队友
- 等级上限 12 级，无二周目继承

## 二、操作速览

| 按键 | 功能 | 说明 |
|------|------|------|
| `F5` | 快速存档 | 随时能用，建议经常按 |
| `F8` | 快速读档 | 回到最近一次存档 |
| `Tab` | 切换角色/队伍视角 | 查看整队背包和角色面板 |
| `I` | 打开背包 | 看物品、装备、使用药水 |
| `M` | 打开地图 | 可传送至已解锁的传送点 |
| `~` | 高亮可交互物品 | 按住不松，视野内所有可捡/可用的东西会亮 |
| `Ctrl` | 显示物品名标签 | 防止漏捡 |
| `Shift+空格` | 切换回合制/即时模式 | 战斗会自动进入回合制，平时可手动开启来精准操作 |
| `N` | 角色面板 | 看属性、技能、法术书 |

## 三、界面怎么看

游戏界面核心四块：

1. **左下角** → 队伍头像。显示四个人的血量（红色条），蓝条/紫条代表法术位
2. **底部栏** → 快捷操作。你可以拖技能、物品到这里方便使用
3. **右上角小地图** → 探索导航。黄色标记 = 任务目标。红色 = 敌人
4. **右下角** → 战斗中显示行动顺序（谁先动手）

## 四、角色属性详解（读懂了就等于入门了）

每个角色有6个属性。数字越高越好，但你看的是**调整值（Modifier）**而不是属性本身：

> 属性值 − 10 ÷ 2（向下取整）= 调整值
> 16 → +3，14 → +2，12 → +1，10 → +0，8 → -1

| 属性 | 简称 | 影响什么 | 谁需要高 |
|------|------|---------|---------|
| **力量** | STR | 近战命中/伤害、跳跃距离、负重、推人成功率 | 战士、野蛮人、圣武士 |
| **敏捷** | DEX | 远程命中/伤害、护甲等级(AC)、先攻、潜行、巧手 | 游荡者、游侠、武僧 |
| **体质** | CON | 生命值(HP)、专注法术的豁免 | **所有人都需要至少14** |
| **智力** | INT | 法师法术、调查/历史/奥秘知识 | 法师 |
| **感知** | WIS | 牧师/德鲁伊法术、察觉(发现陷阱)、洞悉(识破谎言) | 牧师、德鲁伊、武僧 |
| **魅力** | CHA | 术士/邪术师/诗人法术、所有对话检定 | 术士、邪术师、诗人、圣武士 |

## 五、核心战斗术语

### AC（护甲等级 Armor Class）

> **AC = 你的"闪避+防御"数值。敌人攻击投骰 ≥ 你的AC = 你被打中了。**

AC 越高越好（前期 16 算好，后期 20+ 是重甲标配）。AC 的计算方式取决于你穿的护甲类型：

- 无甲/布甲：10 + 敏捷调整值
- 轻甲：护甲基础值 + 敏捷调整值（全额）
- 中甲：护甲基础值 + 敏捷调整值（最多 +2）
- 重甲：护甲基础值固定，敏捷不加成

### HP（生命值 Hit Points）

> **HP = 你的血量。降到0就倒地（需要队友协助或治疗拉起）。完全降到负数 = 死亡。**

升级时 HP 增加量 = 生命骰一半 + 体质调整值。例如战士（生命骰 D10）+ 体质 +3，每级增约 8 HP。

### 攻击加值（Attack Bonus）

> **攻击时，投 D20 + 攻击加值 vs 目标AC。大于等于AC = 命中。**

攻击加值 = 属性调整值 + 熟练加值。用力量武器就加力量调整值，用远程就加敏捷调整值。熟练加值随等级增长（1级 = +2，5级 = +3，9级 = +4）。

### 豁免检定（Saving Throw）

> **当你被法术/毒素/陷阱影响时，投 D20 + 对应属性调整值 + 熟练加值 vs 法术DC。通过 = 效果减弱或无效。**

例如：火球术需要敏捷豁免（躲开爆炸），定身术需要感知豁免（抵抗精神控制），毒素需要体质豁免（身体对抗毒素）。

### 法术 DC（Difficulty Class）

> **你施法时，敌人需要投豁免来抵抗你的法术。DC = 8 + 施法属性调整值 + 熟练加值。**

DC 越高，敌人越难抵抗。前期 13 算正常，后期 17+ 才算合格。

### 法术位（Spell Slots）

> **施法需要消耗法术位。戏法（Cantrip）不消耗，可以无限用。1环到6环消耗对应法术位。**

法术位用完了只能**长休**恢复（邪术师例外，短休恢复）。这是施法职业最核心的资源管理。

### 专注（Concentration）

> **某些强力法术需要"专注"维持。同时只能专注一个法术。受到伤害可能打断专注。**

打断判定：受到伤害→投体质豁免（DC = 10 或 受伤量/2，取更高值）。失败 = 法术中断。要保持专注，施法者离前线远一点，开战前喝药或施法保护自己。

## 六、骰子系统

游戏核心是**D20骰子**（20面骰子）。几乎所有行动都是：

> **投 D20 + 加值 vs 目标难度。大于等于 = 成功。投出 20 = 必定成功（攻击时暴击）。投出 1 = 必定失败。**

### 优劣势（Advantage / Disadvantage）

> - **优势**：投两个 D20，取较高的结果（数学上 ≈ +5 加值）
> - **劣势**：投两个 D20，取较低的结果（≈ -5 惩罚）

获得优势的常见方式：从隐匿状态攻击、攻击倒地的敌人、在高地攻击低地。获得劣势的常见方式：远程攻击时敌人站在你旁边、在低地攻击高地、目盲/中毒。

## 七、回合制战斗

每回合你可以做的事：

| 资源 | 数量 | 用途 |
|------|------|------|
| **动作（Action）** | 1次/回合 | 攻击、施法(大部分)、疾走、撤离、推击 |
| **附赠动作（Bonus Action）** | 1次/回合 | 跳跃、喝药水、副手攻击、部分法术如治疗真言 |
| **移动（Movement）** | 约9m/回合 | 随意分配，可移动→攻击→再移动到别处 |
| **反应（Reaction）** | 1次/轮 | 借机攻击、法术反制、护盾术等。在他人回合也可触发 |

:::tip 别忘了你的附赠动作
新手最容易浪费的就是附赠动作——**每回合都有，不用就浪费了**。起码跳跃一下多走几步路，或者喝一瓶治疗药水。
:::

## 八、短休 vs 长休

| | 短休 | 长休 |
|------|------|------|
| 次数 | 每天 2 次 | 无限（每次消耗 40 补给） |
| 回血 | 消耗生命骰回复 | 完全回复 |
| 法术位 | 邪术师恢复 | 全部施法者恢复 |
| 恢复资源 | 战士动作如潮、武僧气点 | 所有资源 |
| 剧情触发 | 无 | **推进队友对话和剧情事件** |

:::warning 一定要多长休！
BG3 不像传统 D&D 那样惩罚频繁休息。建议每 2~3 场战斗或法术位见底时就长休。队友剧情几乎都在长休时触发，不长休会错过大量对话。
:::

## 九、第一个角色推荐

### 新手最佳：战士 → 战斗大师（Battle Master）

**为什么推荐战士？**

- 不需要管理法术位——你不是施法者。攻击就行，简单直观
- 所有护甲都能穿——AC 前期就能堆到 16~18，很难被打死
- 动作如潮（Action Surge）——2级就能一回合攻击两次，爆发秒杀关键目标
- 11级三重额外攻击——一回合三次主动攻击，别的职业做不到
- 回气——每短休自回 1D10 + 等级生命值，奶妈不是必须的

**战斗大师子职业（3级可选）：** 获得卓越骰（d8），可用于精准打击（补命中）、绊摔打击（打倒地）、缴械打击（卸武器）。操作有深度但好理解。

### 种族选什么？

**半精灵**（万金油，额外技能 + 黑暗视觉）或者**人类**（负重 + 额外技能）。都不影响核心玩法，选看着顺眼的。

### 属性怎么分（27点购）

STR 17 → DEX 10 → CON 16 → INT 8 → WIS 10 → CHA 10

加种族 +2 到 STR 最终 19，+1 到 CON 最终 17。4级专长把 STR 升到 20。

## 十、序章 ~ 第一章第一小时路线

1. **序章·鹦鹉螺号**：只管往前走，每个房间捡东西。第二个房间舱体里救影心——别忘了她。战斗不用硬打，跑到控制台连接，倒计时结束前到逃生舱
2. **坠机海滩**：醒来后搜索附近，捡到铲子。找到影心（沙滩北侧），阿斯代伦（向南海滩），盖尔（传送门里伸手拉他出来）
3. **德鲁伊林地**：向东走。进林地后和所有人对话——这是第一章的任务中心
4. **收队友**：林地训练场找威尔，林地北部笼子救莱埃泽尔，晋升之路河边找卡菈克
5. **第一个商贩**：林地商人阿伦——买 +1 武器、治疗药水。德里斯——买防护戒指

:::warning 新手的6个保命习惯
1. **F5 经常按** — 关键抉择前、开战前、对话前必存档
2. **按住 ~ 搜刮一切** — 箱子、桶、尸体、书架全查
3. **和所有人说话** — 任务藏在对话里
4. **多长休** — 别一路硬打，法术用完就休息
5. **4 个人一起发展** — 不要只练主角
6. **别卖金色的东西** — 传说装备可能前期看着一般，其实是毕业装
:::
