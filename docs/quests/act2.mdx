## 推荐路线

1. **进入暗影之地** → 获取月亮提灯/精灵祝福（免疫暗影诅咒）
2. **终焉光明旅店** → 保护伊索贝尔（不能被抓走！）→ 贾希拉入队 → 达蒙修卡菈克引擎
3. **月出之塔** → 渗透（假装真魂者）→ 监狱救人（明萨拉/侏儒）→ 买风险戒指
4. **莎尔神殿** → 三大试炼 → 暗夜之歌抉择（影心：杀=暗夜法官/不杀=塞伦涅）
5. **夺心魔殖民地** → 凯瑟里克 → 米尔寇使徒最终Boss
6. → 进入第三章

## 影心·暗夜之歌抉择

| 选择 | 后果 |
|------|------|
| **杀暗夜之歌** | 暗夜法官路线，影心变黑暗，暗夜之歌死亡 |
| **不杀（推荐）** | 影心转向塞伦涅，暗夜之歌助战后续Boss |
