## 推荐路线

1. **序章·鹦鹉螺号** → 救影心 → 控制台 → 逃生舱
2. **坠机海滩** → 搜刮 → 找影心 → 阿斯代伦 → 盖尔(传送门)
3. **德鲁伊林地** → 和所有人对话 → 商人买装备 → 收威尔
4. **染疫村落** → 药剂师地窖(死灵之书) → 蜘蛛洞
5. **地精营地** → 三首领(迦特暗杀/明萨拉击晕/拉格兹林最后)
6. **晋升之路** → 卡菈克招募 → 豺狼人伏击
7. **沃金休眠地** → 限时救弗洛里克 → 散塔林会入口
8. **沼泽鬼婆** → 先救梅里娜再杀 → 可选头皮(+1属性)
9. **幽暗地域**（四入口任选）→ 蕈人村 → 奥术塔 → 精金熔炉
10. **山隘/养育间** → 洛山达神殿 → 净化装置 → 进入第二章
