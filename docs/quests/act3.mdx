## 推荐顺序

1. 飞龙岩要塞 → 戈塔什加冕
2. 下城区支线 → 清装备、升级
3. 钢铁铸造厂 → 救贡德信徒 → 摧毁工厂
4. 钢铁王座 → 限时6回合营救
5. 卡扎多尔宫殿 → 阿斯代伦个人任务
6. 巴尔神殿 → 奥林1v1 → 沙洛佛克
7. 希望之邸 → 拉斐尔 → 俄耳甫斯之锤
8. 最终战 → 虚空脑

## 钢铁王座：6回合限时营救

分三路行动：北→欧贝伦公爵、南→奥米伦、西→贡德信徒。每人加速药水+迷踪步。6回合所有人必须上潜艇。

## 希望之邸：拉斐尔

**优先拆4根灵魂柱**（解除魔法/+摧毁）。每根柱子给拉斐尔加buff。救霍普获得治疗支援。带控制法术（定身术、催眠图纹）。
