> D20 结果 + 属性加值 + 熟练加值 ≥ DC → 成功

投出 **20 = 大成功**（必定命中，攻击时暴击伤害翻倍）。投出 **1 = 大失败**（必定失败，无论加值多少）。

## 六大属性详解

属性值 − 10 ÷ 2（向下取整）= 调整值。16 → +3，14 → +2，12 → +1，10 → +0，8 → -1。

| 属性 | 简称 | 决定什么 | 谁需要高 |
|------|------|---------|---------|
| **力量** | STR | 近战命中/伤害 · 跳跃距离 · 负重 · 推人成功率 | 战士 · 野蛮人 · 圣武士 |
| **敏捷** | DEX | 远程命中/伤害 · AC · 先攻 · 潜行 · 巧手(开锁) | 游荡者 · 游侠 · 武僧 |
| **体质** | CON | HP · 专注豁免 · 毒素抵抗 | **所有人至少 14** |
| **智力** | INT | 法师法术 · 调查 · 历史 · 奥秘检定 | 法师 |
| **感知** | WIS | 牧师/德鲁伊法术 · 察觉(发现陷阱) · 洞悉(识破谎言) · 医药 | 牧师 · 德鲁伊 · 武僧 |
| **魅力** | CHA | 术士/诗人/邪术师法术 · 所有对话检定（说服/欺瞒/威吓/表演） | 术士 · 诗人 · 邪术师 · 圣武士 |

## AC — 护甲等级（Armor Class）

**AC = 你的防御数值。敌人攻击投骰 ≥ 你的AC = 被打中。** AC 越高越好。前期 16 算正常，后期 20+ 是重甲标配。

| 护甲类型 | AC 计算公式 | 示例 |
|---------|-----------|------|
| 无甲 / 布甲 | 10 + 敏捷调整值 | 敏捷 16 → AC 13 |
| 法师护甲 | 13 + 敏捷调整值 | 敏 16 → AC 16 |
| 轻甲 | 护甲值 + 敏捷调整值(全额) | 皮甲(11) + 敏16(+3) → AC 14 |
| 中甲 | 护甲值 + 敏捷调整值(最高+2) | 半身甲(15) + 敏14(+2) → AC 17 |
| 重甲 | 护甲值固定，敏捷不计入 | 全身甲 = **AC 18** |
| 野蛮人无甲防御 | 10 + 敏捷调整值 + 体质调整值 | 敏14(+2) + 体16(+3) → AC 15 |
| 武僧无甲防御 | 10 + 敏捷调整值 + 感知调整值 | 敏16(+3) + 感16(+3) → AC 16 |

## HP / 法术位 / 专注 / 法术 DC

| 概念 | 说明 |
|------|------|
| **HP（生命值）** | 0血 = 倒地需协助。完全负数 = 死亡需复活卷轴。升级 HP 增量 = 生命骰一半 + 体质调整值。战士(D10)+体质+3 → 每级约 8HP |
| **法术位（Spell Slots）** | 施法资源。戏法(Cantrip)无限使用。1-6环消耗对应法术位。长休恢复全部（邪术师例外：少量但短休恢复） |
| **专注（Concentration）** | 部分强力法术需专注维持。同时只能专注**一个**。受到伤害→体质豁免(DC=10或伤半取高)→失败=专注中断法术失效。战地施法者专长给优势 |
| **法术 DC** | 8 + 施法属性调整值 + 熟练加值。敌人需投豁免 ≥ 你的DC来抵抗你的法术。前期13正常，后期17+合格 |

## 回合制战斗 · 每回合资源

| 资源 | 数量 | 用途 | 不要浪费 |
|------|------|------|---------|
| ⚡ 动作 | 1次 | 攻击 · 施法(大部分) · 疾走(移速翻倍) · 撤离(不被借机) · 推击 | 加速术额外+1动作。动作如潮(战士2级)再+1 |
| 🔹 附赠动作 | 1次/回合 | 跳跃 · 喝药水 · 副手攻击 · 推击 · 部分法术(治疗真言/灵体武器) | **每回合都有！新手最常忘记用** |
| 🏃 移动 | ~9m | 可拆分使用：移动→攻击→再移动 | 跳跃跨障碍。记住能走就能跳 |
| 🔄 反应 | 1次/轮 | 借机攻击 · 法术反制 · 护盾术 · 防护攻击 | 他人在你回合外触发也可用 |

## 第一小时手把手路线

1. **序章 · 鹦鹉螺号** — 往前走捡东西。第二个房间舱体里救影心。控制台连接→限时 15 回合逃到逃生舱
2. **坠机海滩** — 按住 `~` 搜刮一切。影心(北侧沙滩)、阿斯代伦(南侧小径)、盖尔(路边不稳定传送门→伸手拉他出来)
3. **德鲁伊林地** — 核心任务中心。和所有人对话。商人阿伦买+1武器和治疗药水。德里斯买防护戒指(豁免+1)
4. **收齐队友** — 林地训练场→威尔。林地北部笼子→救莱埃泽尔。晋升之路河边→卡菈克
5. **第一个商贩购物清单** — +1 武器 · 防护戒指 · 治疗药水 ×5 · 羽落卷轴 ×2
