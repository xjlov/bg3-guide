游戏中几乎所有不确定的行动都是**投一个20面骰子(D20)+加值，与难度等级(DC)比较**：

> D20结果 + 属性加值 + 熟练加值 ≥ DC → 成功

**投出20 = 大成功**（攻击时造成暴击，伤害翻倍）  
**投出1 = 大失败**（必定失败，无论加值多少）

## 六大属性详解

| 属性 | 简称 | 影响什么 | 谁需要高 |
|------|------|---------|---------|
| **力量** | STR | 近战命中/伤害、跳跃距离、负重 | 战士、野蛮人、圣武士 |
| **敏捷** | DEX | 远程命中/伤害、AC、先攻、潜行 | 游荡者、游侠、武僧 |
| **体质** | CON | HP、专注豁免 | **所有人14+** |
| **智力** | INT | 法师法术、调查/奥秘 | 法师 |
| **感知** | WIS | 牧师/德鲁伊法术、察觉(发现陷阱) | 牧师、德鲁伊、武僧 |
| **魅力** | CHA | 术士/邪术师/诗人法术、所有对话 | 术士、诗人、圣武士 |

> 属性值 − 10 ÷ 2（向下取整）= 调整值。16 → +3，14 → +2，10 → +0，8 → -1

## AC（护甲等级）

**AC = 你的防御数值。敌人攻击投骰 ≥ 你的AC = 被打中。**

| 护甲类型 | AC计算公式 | 示例 |
|---------|-----------|------|
| 无甲/布甲 | 10 + 敏捷调整值 | 敏捷16 → AC 13 |
| 轻甲 | 护甲值 + 敏捷调整值(全额) | 皮甲(11) + 敏捷16(+3) → AC 14 |
| 中甲 | 护甲值 + 敏捷调整值(最高+2) | 半身甲(15) + 敏捷14(+2) → AC 17 |
| 重甲 | 护甲值固定 | 全身甲(18) → AC 18 |

## HP（生命值）

0血倒地需队友协助拉起。完全负数=死亡。  
升级HP增加量 = 生命骰一半 + 体质调整值。战士(D10)+体质+3 → 每级约8HP。

## 法术位与专注

| 概念 | 说明 |
|------|------|
| **法术位** | 施法消耗。戏法无限，1-6环消耗位。长休恢复 |
| **专注** | 部分法术需专注维持。同时只能1个。受伤可能打断 |
| **法术DC** | 8 + 施法属性调整值 + 熟练加值。敌人需投豁免抵抗 |

## 优劣势

- **优势**：骰两个D20取高的（≈+5加值）。从隐匿攻击、攻击倒地敌人、高地打低地获得
- **劣势**：骰两个D20取低的（≈-5惩罚）。远程被近身、低地打高地、目盲/中毒

## 回合制战斗每回合资源

| 资源 | 数量 | 用途 |
|------|------|------|
| 动作 | 1次 | 攻击、施法、疾走、推击 |
| 附赠动作 | 1次 | 跳跃、喝药、副手攻击、治疗真言 |
| 移动 | ~9m | 可移动→攻击→再移动 |
| 反应 | 1次/轮 | 借机攻击、法术反制 |

## 新手推荐：战士（战斗大师）

- 不需要管理法术位，攻击简单
- 全护甲熟练，AC前期16-18
- 2级动作如潮一回合两次攻击
- 回气自回血，不需要奶妈
- STR17 / DEX10 / CON16 / INT8 / WIS10 / CHA10

## 第一小时路线

1. **鹦鹉螺号** — 往前走捡东西，救影心（舱体），控制台→逃生舱
2. **坠机海滩** — 搜刮，找影心(北)、阿斯代伦(南)、盖尔(传送门伸手)
3. **德鲁伊林地** — 和所有人对话。商人买+1武器和治疗药水
4. **收队友** — 林地训练场威尔、北笼莱埃泽尔、晋升之路河边卡菈克
