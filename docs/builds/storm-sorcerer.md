# 风暴术士 (Storm Sorcerer)

## 构建概览

风暴术士是《博德之门3》Patch 7中法术爆发伤害最高的构建。采用**术士10 / 风暴牧师2**的分割（或纯术士12），本构建通过"湿润状态 + 引导神力最大化 + 闪电法术"三层叠加，实现单回合内造成400+法术伤害的恐怖爆发。

**核心标签**：法术爆发、闪电、湿润组合、AoE清场、Boss速杀

### 构建优势

| 优势 | 说明 |
|------|------|
| 最高法术爆发 | 湿润(伤害翻倍) + 毁灭之怒(最大化) + 成双超魔(双目标) = 单个闪电束可打出160+伤害 |
| AoE清场能力 | 闪电束(直线AoE)、连锁闪电(跳跃AoE)、冰风暴(范围) -- 清杂兵效率极高 |
| 战术机动性 | 风暴术飞行(施法后附赠飞行10尺不触发借机) -- 施法后立刻安全位移 |
| 超魔灵活性 | 成双超魔(双目标)、瞬发超魔(附赠施法)、升阶超魔(敌人豁免劣势) -- 战术选择多样 |
| 简易湿润机制 | 造水术(1环)创造湿润状态 -- 不需要队友配合 |

### 构建劣势

| 劣势 | 说明 |
|------|------|
| 极度依赖湿润 | 没有湿润状态时闪电伤害减半 -- 对闪电免疫/抗性敌人输出大幅降低 |
| 法术位有限 | 术士的法术位比法师少 -- 高环法术位需要精心管理 |
| 体质脆弱 | d6生命骰 -- 如果没有警觉先攻，可能被先手秒杀 |
| 闪电单一伤害类型 | 遇到闪电免疫/抗性敌人时输出受限 -- 需要备选冰霜法术 |
| 引导神力有限 | 毁灭之怒每短休仅1次 -- 多场战斗需要判断使用时机 |

## 核心机制深度解析

### 机制一：湿润状态 (Wet Condition)

湿润是本构建的**核心伤害放大器**：

| 湿润的来源 | 方法 | 评价 |
|------------|------|------|
| **造水术 (Create Water)** | 牧师1环法术 -- 18m范围创造湿润地面，区域内敌人获得湿润状态 | 最可靠，自带(兼职牧师) |
| **降雨术 (Rain)** | 德鲁伊/自然领域的法术 -- 更大范围降雨 | 需要队友 |
| **水罐/水瓶投掷** | 低tech方法 -- 投掷水罐湿润1-2个目标 | 不消耗法术位 |
| **队友协助** | 牧师队友施放造水术节省你的法术位 | 最佳方案 |

**湿润的效果**：
- 雷电伤害翻倍(x2)
- 冰霜伤害翻倍(x2)
- 火焰伤害减半(x0.5)
- 可以用冰冻法术冻结湿润目标(额外的控制效果)

**湿润的伤害影响数字**：

```
闪电束(Lightning Bolt, 3环)：8d6
  无湿润平均：8 x 3.5 = 28
  湿润平均：8 x 3.5 x 2 = 56
  湿润+最大化：8 x 6 x 2 = 96

连锁闪电(Chain Lightning, 6环)：10d8
  无湿润平均：10 x 4.5 = 45
  湿润平均：10 x 4.5 x 2 = 90
  湿润+最大化：10 x 8 x 2 = 160 (跳4个目标 = 640总伤害潜力)
```

### 机制二：风暴牧师引导神力 (Destructive Wrath)

风暴领域牧师2级的引导神力：

| 属性 | 说明 |
|------|------|
| **毁灭之怒** | 当施放造成雷电或雷鸣伤害的法术时，使用引导神力使伤害骰全部取**最大值** |
| 使用次数 | 1次/短休 |
| 适用法术 | 闪电束、连锁闪电、巫术闪电、冰风暴(雷鸣部分)、粉碎音波 |

**引导神力的数学价值**：

```
闪电束(3环, 8d6)：
  平均值：28
  最大值：48
  提升：+20 额外伤害 (+71%)

连锁闪电(6环, 10d8)：
  平均值：45
  最大值：80
  提升：+35 额外伤害 (+78%)

加上湿润后：
  闪电束(3环)：8 x 6 x 2 = 96 (最大化+湿润)
  连锁闪电(6环)：10 x 8 x 2 = 160 (最大化+湿润)
```

### 机制三：术士超魔 (Metamagic)

| 超魔 | 消耗 | 效果 | 使用场景 |
|------|------|------|----------|
| **成双超魔 (Twinned Spell)** | 1术法点/环位 | 对单目标法术复制到第二个目标。连锁闪电可成双=4个目标各受10d8最大化伤害 | Boss+副目标同时爆发 |
| **瞬发超魔 (Quickened Spell)** | 3术法点 | 施法时间从动作变为附赠动作。腾出主动动作进行另一法术或戏法 | 湿润(动作) + 瞬发闪电束(附赠) = 同一回合完成湿润+爆发 |
| **升阶超魔 (Heightened Spell)** | 3术法点 | 目标对法术的第一次豁免获得劣势 | 保证关键控制法术命中(怪物定身术等) |

## 完整升级路线：逐级详细拆解

### 第1级：术士1（风暴术）

```
职业：术士1(风暴术)
生命骰：1d6 + 3(体质) = 9 HP
熟练加值：+2
术法点：0 (3级获得)
```

**获得的能力**：

| 能力 | 类型 | 详细说明 |
|------|------|----------|
| **风暴术 (Storm Sorcery)** | 子职业 | 施放1环或更高环法术(非戏法)后，可以附赠动作**飞行**最多10尺，不触发借机攻击。这是风暴术的核心机动性 |
| **风暴语言 (Wind Speaker)** | 子职业 | 获得原初语(Primordial)熟练 -- 与元素生物对话 |
| **1环法术位 x2** | 施法 | 2个1环法术位 |
| **已知戏法 x4** | 施法 | 4个戏法 |
| **已知法术 x2** | 施法 | 2个1环法术 |

**推荐戏法**：

| 戏法 | 用途 |
|------|------|
| **冰霜射线 (Ray of Frost)** | 1d8->3d8冰霜伤害 + 目标移速-3m。湿润下翻倍！前期主力戏法 |
| **电击之触 (Shocking Grasp)** | 1d8->3d8闪电伤害(近战)，目标无法反应。湿润下翻倍！近战脱身用 |
| **交友术 (Friends)** | 对话魅力检定优势 |
| **法师之手 (Mage Hand)** | 远程互动 |
| **次级幻影 (Minor Illusion)** | 吸引敌人集中(配合AoE) |
| **光亮术 (Light)** | 实用 |

**推荐法术**：

| 法术 | 用途 |
|------|------|
| **巫术闪电 (Witch Bolt)** | 1d12闪电/回合(专注)。湿润下翻倍。前期单体最强(但需专注--后续会被更好的法术替代) |
| **冰霜匕首 (Ice Knife)** | 1d10穿刺+2d6冰霜范围。湿润下冰霜翻倍！优秀的1环AoE |
| **魔法飞弹 (Magic Missile)** | 3d4+3必中力场。无法被湿润加成但100%命中 |

**战斗策略(1级)**：
- 主力：冰霜射线(戏法) -- 1d8冰霜，湿润下=2d8=平均9
- AoE：冰霜匕首 -- 1d10+2d6冰霜，湿润下冰霜=4d6=平均14
- 施法后附赠飞行10尺 -- 不触发借机！利用这个保持安全距离
- 9 HP非常脆弱 -- 保持后排位置

**获得的能力**：

| 能力 | 类型 | 详细说明 |

| **领域法术** | 子职业 | 1环：造水术、雷电波(总是准备) |
| **牧师法术** | 施法 | 准备感知调整值+1个牧师法术(仅1个 -- 感知10)。推荐：**治愈真言**(附赠复活)、**祝福术**(实用buff) |

**为什么此时兼职牧师？**
1. 术士5级已获得3环法术(闪电束)和5个术法点 -- 核心能力已就位
2. 下一级(牧师2)获得**毁灭之怒** -- 与闪电束形成质变
3. 造水术(领域法术)现在可以自己制造湿润状态
4. 重甲熟练大幅提升AC和生存力

**兼职牧师的代价**：
- 延迟高环法术(闪电束已经获得，所以损失最小)
- 牧师法术位基于感知(仅10) -- 1环仅1个法术准备
- 延迟术士的后续ASIs和超魔

## 战斗轮换

### 标准回合 -- 单目标爆发

```
准备条件：无（自给自足）

步骤1：动作 -- 造水术(Create Water)
  目标位置18m范围，创造湿润地面。范围内所有敌人获得湿润状态。
  （如果队友已经施放造水术/降雨术，跳过此步骤！）

步骤2：引导神力：毁灭之怒
  自由动作（非动作/附赠），宣布本次施法使用引导神力

步骤3：动作 -- 成双超魔 + 闪电束(3环)
  8d6闪电，全部取最大值(引导神力) = 48
  湿润翻倍 = 48 x 2 = 96 伤害
  成双超魔 = 复制到第2个目标 = 每个目标 96 = 总计192伤害

步骤4：附赠动作 -- 风暴术飞行10尺
  施法后附赠飞行，不触发借机 -- 脱离危险位置

总计：单回合192伤害(双目标) / 96伤害(单目标)
```

### 标准回合 -- AoE清场

```
步骤1：队友或自己(如果上回合已准备) -- 造水术创造湿润区域
步骤2：引导神力：毁灭之怒
步骤3：动作 -- 闪电束(3环)
  选择一条经过多个敌人的直线
  每个湿润敌人：8 x 6 x 2 = 96 伤害
  如果5个敌人一排 = 5 x 96 = 480总伤害
步骤4：附赠飞行脱离

替代AoE：冰风暴(4环)
  4d6冰霜湿润翻倍=8d6=28 + 2d8钝击=9 = 37/目标
  虽然不如闪电束爆发高，但不消耗引导神力
```

```
├── 成双闪电束: 3术法点(3环)

├── 升阶超魔(控制): 3术法点
└── 如果术法点不足: 消耗低环法术位转换
```

### 超魔使用优先级

| 优先级 | 超魔 | 使用条件 |
|--------|------|----------|
| **最高** | 成双超魔 | Boss战 -- 将单体高环闪电复制到双目标 |
| **高** | 瞬发超魔 | 需要同一回合完成湿润+爆发 |
| **中** | 升阶超魔 | 关键控制法术(怪物定身术) -- 确保豁免失败 |
| **低** | 谨慎超魔(Careful Spell) | 如果队友在闪电束直线中 |

## 常见问题与误区

:::danger 误区：火焰法术也受湿润加成
湿润状态让火焰伤害**减半**(x0.5)而非翻倍！只有**雷电和冰霜**伤害在湿润状态下翻倍。不要使用火焰法术(火球术、灼热射线等)对湿润目标 -- 伤害反而减半。
:::

:::warning 关于引导神力的使用时机
毁灭之怒每短休只能用1次。不要浪费在小战斗上 -- 保存给：
1. Boss战
2. 多个高价值目标同时在场
3. 需要速杀的关键敌人(敌方施法者、治疗者)

在非引导神力战斗中，依赖湿润翻倍+成双超魔即可 -- 没有最大化也有56伤害(AoE)，足够秒杀杂兵。
:::

:::tip 湿润的创造技巧
1. **投掷水罐** = 不消耗法术位。多带几个水罐在包里！
2. **造水法杖(Rain Dancer)** = 每短休免费造水术
3. **队友牧师** = 让你的牧师队友负责造水(他们有更多低环法术位)
4. **预湿润** = 在战斗开始前的潜行阶段施放造水术 -- 不消耗战斗动作
5. **水元素召唤** = 某些法术/物品可召唤水元素 -- 水元素的攻击自带湿润
:::

:::danger 闪电免疫/抗性敌人
第三章有大量闪电抗性敌人：
- 构装体(钢铁守卫等)：闪电免疫或抗性
- 某些恶魔：闪电抗性
- 龙类(蓝龙/青铜龙)：闪电免疫

对抗这些敌人时：
- **元素导师(闪电)** = 忽略抗性，但不能忽略免疫
- 闪电免疫 = 改用**冰霜法术**(寒冰锥、冰风暴) -- 同样享受湿润翻倍
- 或改用不依赖元素伤害的控制法术(催眠图文、怪物定身术)
:::

## 总结

风暴术士是BG3中爆发伤害最高、最具毁灭性的法术构建。

**核心游戏计划**：
1. 创造湿润状态(造水术/队友/水罐)
2. 引导神力：毁灭之怒
3. 闪电束(3环)或连锁闪电(6环) = 最大化+湿润翻倍
4. 成双超魔打双目标 = 伤害翻倍
5. Boss战叠加瞬发超魔和加速 = 单回合3次闪电法术

**伤害三层次**：
- 基础：闪电束 = 28伤害
- +湿润：闪电束 = 56伤害(翻倍)
- +湿润+最大化：闪电束 = 96伤害(翻倍+最大化)
- +成双：96 x 2目标 = 192总伤害

**装备核心**：
- 马科赫什基尔(免费连锁闪电+闪电束)
- 造水法杖(免费造水术) -- 过渡装备
- 致命一击戒指(法术攻击优势)
- 高等生命护符(生存)

**适合人群**：
- 喜欢大数字的玩家 -- 单发160伤害的快感
- 喜欢AoE清场的玩家 -- 闪电束一条线秒杀所有敌人
- 喜欢战术深度的玩家 -- 湿润管理+超魔选择+引导神力时机
- 想要Boss快速击杀的玩家 -- 引爆发=绝大多数boss一回合残血或死亡
