# 风暴术士 (Storm Sorcerer)

**全游最高法术爆发** — 术士10级 + 风暴牧师2级的湿润闪电最大化组合，单个闪电链可打出240+伤害。利用造水术/降雨术创造湿润状态，雷电/冰霜伤害翻倍，配合风暴牧师引导神力最大化。

***

## 核心机制

伤害链由三层叠加：

**第一层 — 湿润(Wet):** 目标处于湿润状态时，雷电和冰霜伤害**翻倍**。通过降雨术(一级法术)、造水术(牧师/德鲁伊)或投掷水罐实现。

**第二层 — 风暴牧师引导神力:** 风暴领域2级获得**毁灭之怒(Destructive Wrath)**——使用引导神力使雷电/雷鸣伤害骰全部取**最大值**。

**第三层 — 术士超魔:** 成双超魔(Twinned Spell)将单目标闪电法术复制到第二个目标；瞬发超魔(Quickened Spell)将法术转为附赠施法，腾出主动动作施放戏法或另一法术。

**完整爆发流程:**
1. 降雨术创造湿润区域 (或队友造水)
2. 引导神力：毁灭之怒 (伤害骰最大化)
3. 成双超魔 + 三环闪电束 → 两个目标各 8d6 × 2(湿润) = 各 96 伤害(Lv3)
4. 瞬发超魔 戏法(湿润下冰霜射线3d8×2=48)或升环闪电(取决于资源)

## 战斗循环

**战斗前:**
1. 确认牧师引导神力可用 (短休恢复)
2. 装备马科赫什基尔获得免费闪电法术

**标准开场:**
1. **造水术**(附赠动作/主动) → 创造湿润区域覆盖多数敌人
2. 或队友预挂降雨术/投掷水罐

**爆发回合 (BOSS战):**
1. **主动动作** → 成双超魔 + 闪电束(三环) → 湿润下双目标各 8d6×2 max = 各 96
2. 引导神力(可在施法前使用) → 伤害骰取最大值
3. 如果用马科赫什基尔 → 免费施放连锁闪电(六环) → 湿润下 10d8×2 max = 160, 跳4目标
4. **附赠动作** → 瞬发超魔 + 升环闪电/寒冰法术

**理论天花板伤害 (一回合):**
- 成双连锁闪电(Lv6) × 湿润 × 毁灭之怒: 2 × (10×8×2) = 320 伤害(双目标)
- 瞬发成双闪电束(Lv4-5): 再追加 100-150+
- 全部条件对齐一回合可突破 **400+** 法术伤害
