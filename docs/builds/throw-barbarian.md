# 投掷野蛮人 (Throw Barbarian)

**新手最佳远程物理Build** — 狂战士狂怒投掷 + 盗贼额外附赠 + 回旋长矛自动回收，每回合4次投掷，操作简单、伤害稳定、自带控制。

***

## 核心机制

狂战士子职在狂暴状态下获得**狂怒投掷（Frenzied Throw）**作为附赠动作，可投掷武器或物品。与普通投掷不同，狂怒投掷额外造成目标**倒地**（力量豁免DC基于野蛮人力量），提供极强的单体控制。

盗贼3级(盗贼)提供**额外附赠动作**，战士提供**动作如潮**。在加速状态下理论最高伤害投掷次数：主动2次 + 狂怒投掷2次 + 动作如潮2次 = **6次投掷**。

核心武器流程：
- **第一章** → 地精营地商人购**回旋长矛(Returning Pike)**：投掷后自动回手，+1武器
- **第三章** → 风暴海岸圣所拾取**尼鲁纳(Nyrulna)**：传奇三叉戟，投掷造成范围雷电伤害

## 战斗循环

**战斗前:**
1. 装备回旋长矛(或尼鲁纳)
2. 确保投掷手套+投掷戒指双增伤饰品

**标准回合 (狂暴状态下):**
1. **附赠动作** — 启动狂暴(第一轮) / 狂怒投掷
2. **附赠动作2** (盗贼) — 狂怒投掷
3. **主动攻击1** — 投掷回旋长矛
4. **主动攻击2** — 投掷回旋长矛
5. **高地站位** — 投掷从高处获得+2命中加成
6. 每次投掷触发手套+戒指各+1d4，酒馆额外+力量调整值

**狂怒投掷特殊效果:**
- 目标力量豁免失败则**倒地**，获得近战队友攻击优势
- 可投掷敌人(徒手检定)造成坠落伤害+倒地
