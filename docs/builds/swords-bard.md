# 剑舞诗人 (Swords Bard)

## 构建概览

剑舞诗人是《博德之门3》Patch 7 中最全能且输出最高的远程物理构建之一。采用**吟游诗人10级 / 战士2级**的职业分割，本构建将远程物理爆发、法术控制和社交技能完美融合。

**核心标签**：远程DPS、控制、奥术敏锐、双持手弩、社交

### 构建优势

| 优势 | 说明 |
|------|------|
| 远程爆发极高 | 每回合4次远程攻击，动作如潮回合8次攻击，每次附加神射手+10伤害 |
| 法术控制不可抵抗 | 奥术敏锐头盔叠加法术DC，配合神秘恶棍戒指附赠动作控制，敌人几乎无法豁免 |
| 技能全能 | 万事通+专精，几乎任何技能检定都能通过 |
| 资源循环高效 | 激励骰短休恢复，战士能力短休恢复，配合休憩之歌可连续作战 |
| 生存力强 | 中甲+盾牌，AC可达20+，防御华舞额外+4AC |

### 构建劣势

| 劣势 | 说明 |
|------|------|
| 核心装备依赖度高 | 奥术敏锐头盔和神秘恶棍戒指缺一不可，错过则构建大打折扣 |
| 法术位有限 | 仅10级施法者，6环法术位仅用于升环 |
| 前期较弱 | 6级之前远程华舞不可用，需近战过渡 |
| 多属性依赖 | 需要敏捷(攻击)和魅力(法术DC)双属性，专长紧张 |

## 核心机制深度解析

### 机制一：远程挥砍华舞 (Slashing Flourish - Ranged)

剑舞学院3级获得剑技华舞能力，消耗1个吟游诗人激励骰来增强攻击。华舞有近战和远程两种用法：

- **近战挥砍华舞**：对目标造成武器伤害+1d6(随等级增长至1d10)，并对扇形范围内另一个敌人造成武器伤害
- **远程挥砍华舞**（6级解锁）：以远程武器发动，对两个不同目标各造成一次武器伤害+1d6(1d8/1d10)额外伤害

关键规则：
- 远程华舞的**两次攻击都算作一次攻击动作的一部分**，不是额外攻击
- 配合5级诗人获得的额外攻击特性，一个标准攻击动作变为2次华舞，每次华舞打2个目标 = 共4次攻击/回合
- 华舞可以与神射手专长的-5/+10全额叠加
- 每次华舞攻击独立计算命中与伤害

### 机制二：奥术敏锐 + 神秘恶棍组合

这是本构建的**核心装备组合**，也是剑舞诗人能同时输出和控制的关键：

**奥术敏锐 (Arcane Acuity)**：
- 来源：奥术敏锐头盔(Helmet of Arcane Acuity)
- 效果：每次武器攻击命中时获得2层"奥术敏锐"
- 每层效果：法术攻击掷骰+1、法术豁免DC+1
- 最大层数：10层
- 持续时间：2回合（每次获得新层刷新持续时间）
- 标准回合(4次攻击全命中)：8层 = +8法术DC

**神秘恶棍戒指 (Band of the Mystic Scoundrel)**：
- 效果：在使用武器攻击(或华舞)后，可以用附赠动作施放附魔系或幻术系法术
- 可施放法术示例：人类定身术(Hold Person)、怪物定身术(Hold Monster)、指挥术(Command)、塔莎狂笑术(Tasha's Hideous Laughter)、困惑术(Confusion)、催眠图文(Hypnotic Pattern)

**组合运作流程**：
1. 使用攻击动作进行2次远程华舞（共4次武器攻击）
2. 4次命中 = 8层奥术敏锐 = +8法术DC
3. 附赠动作（通过神秘恶棍戒指）施放指挥术:定身(Grovel)
4. 法术DC = 8(基础) + 4(熟练) + 3(魅力16时) + 8(奥术敏锐) = **DC 23**
5. 大多数敌人需要投出18-20才能豁免 —— 近乎必中

### 机制三：动作如潮 (Action Surge)

战士2级的动作如潮让你获得一个额外的动作（短休恢复）。这个额外动作同样享受额外攻击特性：

- 标准回合 = 攻击动作(2次华舞=4次攻击) + 附赠控制
- 动作如潮回合 = 攻击动作(4次攻击) + 动作如潮(4次攻击) + 附赠控制 = **8次攻击 + 控制**
- 8次全部命中 = 16层奥术敏锐(实际上限10层) = +10法术DC

## 属性分配

### 27点购点方案

| 属性 | 购点 | 种族加值 | 最终值 | 调整值 | 说明 |
|------|------|----------|--------|--------|------|
| **力量 (STR)** | 8 | - | 8 | -1 | 远程build，完全不需要力量 |
| **敏捷 (DEX)** | 17 | +2 | **19** | +4 | 🔑 主属性：远程攻击命中/伤害、AC加值、先攻加值、敏捷豁免 |
| **体质 (CON)** | 14 | - | **14** | +2 | HP每级+2，专注豁免(维持高等隐形术/催眠图文) |
| **智力 (INT)** | 8 | - | 8 | -1 | 属性检定额外 |
| **感知 (WIS)** | 10 | - | **10** | +0 | 感知豁免（不可再低以免被控到死） |
| **魅力 (CHA)** | 16 | +1 | **17** | +3 | 🔑 副属性：法术攻击掷骰、法术DC、社交技能、激励骰数量 |

### 属性成长路线

| 等级 | 属性变化 | 敏捷 | 魅力 |
|------|----------|------|------|
| 1级 | 初始 | 19 (+4) | 17 (+3) |
| 4级 | 神射手专长（无属性提升） | 19 (+4) | 17 (+3) |
| 8级 | ASI 敏捷+2 | **20 (+5)** | 17 (+3) |
| 12级 | 战士兼职已完成，无更多ASI | 20 (+5) | 17 (+3) |

:::tip 为什么魅力停在17？
12级的专长选择了警觉(+5先攻)而非ASI魅力+2。在装备支持下(奥术敏锐提供最多+10法术DC)，17魅力已经足以让控制法术必中。先攻的优先级高于法术DC——先出手比法术DC多+1更重要。

如果你极度追求法术DC，可以在12级选择ASI魅力+2代替警觉，但不推荐。
:::

### 可选属性变体

**魅力优先变体**（更侧重控制）：
- 敏捷16(+2)=18，魅力17(+1)=18
- 优点：法术DC+1，更多激励骰
- 缺点：敏18→20需要到8级，前期攻击-1
- 推荐度：⭐⭐⭐

**体质优先变体**（更侧重生存）：
- 敏捷17(+2)=19，体质15，魅力14(+1)=15
- 优点：HP更多，专注更稳
- 缺点：魅力15→16法术DC降低
- 推荐度：⭐⭐

### 专长详细分析

| 等级 | 专长 | 效果 | 选择理由 |
|------|------|------|----------|
| 诗人4 | **神射手 (Sharpshooter)** | 远程攻击可承受-5命中惩罚，获得+10伤害；高低优势自动取消 | 🔑 本构建**伤害核心**。4次攻击×10=每回合+40伤害。配合箭术风格(+2)和奥术敏锐(+命中)抵消惩罚 |
| 诗人8 | **ASI 敏捷+2** | 敏捷19→20，攻击/伤害/AC/先攻/敏捷豁免各+1 | 主属性封顶，全面提升 |
| 诗人10/战士2 | **警觉 (Alert)** | 先攻+5，不会被突袭 | 先攻决定谁先出手——你先叠奥术敏锐并控制全场 vs 敌人先打你 |

### 未选择的重要专长

| 专长 | 为何不选 |
|------|----------|
| **弩专家 (Crossbow Expert)** | 双手弩的副手攻击需要附赠动作，但附赠动作已经用于控制法术(神秘恶棍戒指)，所以副手攻击没用。且近战射击无劣势在远程build中不重要 |
| **战地施法者 (War Caster)** | 战士1级已给体质豁免熟练，专注维持已足够可靠。如果你依然经常被打断专注，可以在警觉的位置选这个 |
| **属性提升(魅力+2)** | 法术DC已由奥术敏锐提供，魅力+1DC远不如先攻+5重要 |
| **双重持用者 (Dual Wielder)** | 手弩已经是轻型武器，不需要此专长来双持。且主副手都是手弩，AC+1不如警觉的+5先攻 |

| 戏法 | 用途 |

| 法术 | 用途 |
|------|------|

- 队友倒地时附赠治愈真言
- 激励骰给关键队友(游荡者开锁、战士关键攻击)

**关键装备推荐（1级可用）**：

| 法术 | 用途 |
|------|------|

- **近战模式**：弯刀+盾牌 + 中甲(AC约17-19)

**装备过渡(3级推荐)**：
- 主手：弯刀+1（或刺剑+1）
- 副手：盾牌
- 盔甲：革甲(AC 14) → 半身板甲(AC 15+敏2=17)
- 头盔：任意

### 第4级：吟游诗人4（专长）

```
职业：吟游诗人4
生命骰：4d8 + 8 = 约36 HP
熟练加值：+2
新增戏法：1个
新增已知法术：1个
```

**获得的能力**：

| 能力 | 类型 | 详细说明 |
|------|------|----------|
| **专长：神射手 (Sharpshooter)** | 专长 | 🔑 远程攻击可承受-5命中惩罚获得+10伤害；高地/低地的优势劣势自动取消(即高低不会互抵命中惩罚) |

**神射手效果详解**：
- 切换开关：可以手动开启/关闭-5/+10
- 使用建议：对AC≤15的敌人全程开启；对AC≥18的需要评估或配合优势/祝福术
- 4级时你的远程攻击加值约为：+2(熟练)+4(敏捷)+2(高处)=+8，开神射手后为+3——对AC15目标命中率45%，对AC12目标命中率60%

**推荐新法术**：

| 法术 | 用途 |
|------|------|
| **云雾术 (Cloud of Daggers)** | 4d4挥砍伤害/回合，无豁免。堵门/狭窄通道极其强力 |
| **匕首云 (Cloud of Daggers)** | 同上，2环优秀持续伤害 |
| **暗示术 (Suggestion)** | 对话外的强力控制，但需专注 |

**获得的能力**：

|------|------|----------|
| **战斗风格：箭术 (Archery)** | 战士 | 🔑 远程武器攻击掷骰**+2**。这是兼职战士最重要的理由之一 |
| **第二口气 (Second Wind)** | 战士 | 附赠动作回复1d10+1 HP(短休恢复) |
| **重甲熟练** | 战士 | 可以穿重甲（但敏捷20时轻甲/中甲AC更高） |
| **体质豁免熟练** | 战士1级 | 🔑 体质豁免+熟练加值(+4)。对维持专注法术(高等隐形术、催眠图文)至关重要 |

**兼职战士的理由详解**：

1. **箭术风格(+2命中)**：这是本构建选择此时兼职的核心原因。+2命中直接抵消神射手-5惩罚的40%，大幅提升输出稳定性。

2. **体质豁免熟练**：10级诗人没有体质豁免熟练——被打断专注的风险很高。战士1级给予体质豁免熟练(+4加值)，配合14体质(+2)，专注豁免=+6，再加上可能的护符或装备，专注基本不会断。

3. **动作如潮准备**：下一级获得动作如潮——8次华舞攻击+控制的爆发回合。

4. **为何不更早兼职？**
   - 5级前兼职会延迟额外攻击(诗人5级)到总等级6——太晚
   - 5-7级兼职会延迟远程华舞(诗人6级)——核心能力
   - 8-10级兼职会延迟魔法秘密(诗人10级)——指挥术和法术反制
   - 因此**诗人10级后**是唯一合理的兼职时间点

**战斗风格为什么不选防御？**
防御风格(+1 AC)很诱人，但+2命中对于神射手构建的优先级远超1点AC。你的生存依靠的是先出手控制全场，而不是多1点AC。

## 战斗轮换

### 标准回合（每回合执行）

```
阶段1：移动阶段
├── 移动到最佳射击位置（通常在高处）
├── 利用木半精灵的10.5m基础速度快速走位
└── 必要时使用迷踪步(护符)/飞行药水

阶段2：攻击阶段
├── 攻击动作：远程挥砍华舞 → 目标A + 目标B各一次远程攻击
│   每次攻击 = 1d6+5(武器+敏) + 1d10(华舞d10) + 10(神射手) + 2(腐蚀戒指)
│   每次攻击 ≈ 5.5 + 5 + 5.5 + 10 + 2 = 28点伤害
│   一轮两次华舞 = 4次攻击 = 约112点伤害
│   命中时叠加奥术敏锐：4次命中 = 8层 = +8法术DC
│
├── 额外攻击：远程挥砍华舞 → 目标C + 目标D各一次远程攻击
│
└── 附赠动作阶段：
    ├── 主要用途：通过神秘恶棍戒指施放指挥术:定身(Grovel)
    │   消耗1环法术位，命令1-3个目标(升环)俯卧一回合
    │   法术DC = 8 + 4(熟练) + 3(魅力) + 8(奥术敏锐) = DC 23
    │   大多数第二章敌人感知/感知豁免约+1~+3，需要投出20来豁免
    │
    └── 备选用途：
        ├── 治愈真言（复活队友）
        ├── 第二口气（自回血，1d10+1）
        ├── 迷踪步（战术位移）
        └── 如无神秘恶棍戒指 → 使用手弩副手攻击（伤害补充）
```

### 爆发回合（动作如潮可用时）

```
适用场景：boss战、需要速杀关键目标、紧急清场

爆发回合执行顺序：
┌─────────────────────────────────────────┐
│ 步骤1：动作如潮 (Action Surge)           │
│ 步骤2：攻击动作 + 额外攻击 → 2次华舞     │
│         = 4次远程攻击（叠8层敏锐）        │
│ 步骤3：动作如潮动作 + 额外攻击 → 2次华舞  │
│         = 4次远程攻击（再叠8层，上限10）   │
│ 步骤4：附赠动作 → 施放控制法术           │
│         （定身术/指挥术，DC加成10）       │
│                                          │
│ 总输出：8次攻击 + 控制法术               │
│ 总伤害：8 × 28 = 224点伤害(平均)         │
│ 法术DC：+10 = 敌人基本无法抵抗           │
└─────────────────────────────────────────┘
```

## 常见问题与误区

:::danger 误区：诗人兼战士应该6级后立刻兼职
在BG3中，诗人5级获得额外攻击和字体激励(短休恢复)，6级获得远程华舞——这些都是质变能力。如果5级后立刻兼职战士，你会把远程华舞推迟到总等级7级(诗人6)，这对你的核心输出循环影响极大。正确的顺序是诗人6级(获得远程华舞)后再考虑兼职。
:::

:::warning 误区：应该用重弩或长弓
手弩的优势在于双持——副手手弩可以作为附赠动作的攻击选项(没有神秘恶棍戒指时)。而且手弩的伤害骰(1d6)与轻弩(1d8)只差1点平均伤害，但获得两次额外附赠攻击的潜力完全碾压。当你有神秘恶棍戒指后，附赠动作用于控制，手弩的意义在于可以双持以应对不同弹药和附魔(地狱火+涅尔)。
:::

:::tip 技巧：如何最大化华舞输出
1. 选择两个相邻的敌人——华舞的第二个目标必须在主目标的扇形/射程内
2. 如果只有一个目标——可以的！两次华舞攻击(攻击动作+额外攻击)可以选择同一目标——总共4次攻击全部打同一个敌人。单体输出没有任何损失
3. 优先攻击集中的敌人——叠奥术敏锐层数更快
:::

:::warning 关于神射手开关
- AC ≤ 15：全程开启神射手
- AC 16-18：有攻击优势(高等隐形/致命戒指)时开启
- AC ≥ 19：关闭神射手，或只在有祝福术+优势时开启
- 如果命中率低于50%，关闭神射手——稳定的伤害比偶尔的大数字更重要
:::

## 总结

剑舞诗人10/战士2是BG3中最全面且最强的构建之一。它同时拥有：

- **远程物理DPS**（4-8次远程攻击/回合，每次约28-50伤害）
- **法术控制**（DC可达25+，敌人几乎无法抵抗）
- **社交技能**（万事通+专精+魅力，对话检定几乎不可能失败）
- **技能全能**（万事通让你在任何技能上都有竞争力）

**核心游戏计划**：
1. 远程华舞叠奥术敏锐
2. 附赠动作(神秘恶棍戒指)施放指挥术:定身/人类定身术
3. 队友收割被控敌人
4. Boss战使用动作如潮+全爆发

**装备核心**：奥术敏锐头盔 + 神秘恶棍戒指（缺一不可）
