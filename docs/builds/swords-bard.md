# 剑舞诗人 (Swords Bard)

**远程DPS天花板 + 万能工具人** — 剑舞学院挥砍华舞双箭齐发，配战士动作如潮实现瞬间爆发，同时拥有全游戏最强的对话技能和法术控场。

***

## 核心机制

剑舞学院吟游诗人的核心是**挥砍华舞（Slashing Flourish）**——消耗一个吟游激励骰，单次攻击可同时命中**两个相邻目标**，每箭附加1d8伤害。配合**远程挥砍华舞**选择同一目标两次，等效于单次攻击造成两次完整远程伤害。

战士2级提供**动作如潮（Action Surge）**，使一轮内获得额外动作。在10级诗人拥有d10激励骰时，一轮爆发可打出：
- 主动动作: 2次攻击 × 每次2箭(华舞) = 4箭
- 动作如潮: 2次攻击 × 每次2箭(华舞) = 4箭
- 合计: **8箭**，每箭1d8+5(敏捷)+10(神射手) = 平均20+伤害

## 战斗循环

**战斗前:**
1. 上激励骰(短休恢复)
2. 确保高风险戒指装备(攻击优势)

**标准回合:**
1. 判断敌人分布 → 两敌相邻用挥砍华舞同时打两个
2. 单体目标用挥砍华舞选同一目标 → 双箭暴击
3. 奥术敏锐头盔每箭叠加，法术DC可叠至30+

**爆发回合 (动作如潮):**
1. 主动动作 → 挥砍华舞 ×2 = 4箭
2. 动作如潮 → 挥砍华舞 ×2 = 4箭
3. 8箭全吃神射手+10 → 理想爆发 **160-200+伤害**
4. 奥术敏锐叠满后接控场法术 (人类定身术/催眠图纹) → DC极高几乎必中
