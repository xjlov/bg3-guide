# 战斗大师战士 (Battle Master Fighter)

## 构建概览

战斗大师战士是《博德之门3》Patch 7中最经典、最可靠的近战物理构建。采用**纯战士12级**无需兼职，本构建以巨武器大师(Great Weapon Master)为核心输出引擎，配合战斗大师的精准打击和多种战技，实现稳定且具有爆发力的每回合输出。

**核心标签**：近战DPS、巨武器、战技控制、纯职业、新手最佳选择

### 构建优势

| 优势 | 说明 |
|------|------|
| 操作直观 | 不需要复杂的兼职和资源管理——砍就对了 |
| 输出稳定 | 三重额外攻击(11级)意味着每回合3次基础攻击，全游戏最高 |
| 容错极高 | d10生命骰+重甲+回气+不屈——极其难以被击杀 |
| 专长最多 | 纯战士12级获得4个专长——全游戏最多 |
| 爆发力强 | 动作如潮+加速=7+次巨武器攻击/回合(11级) |
| 无装备依赖 | 不需要特定传奇装备即可成型——任何强力巨剑/巨斧都可以 |

### 构建劣势

| 劣势 | 说明 |
|------|------|
| 机动性差 | 没有传送或加速能力（除非靠装备/药水） |
| 范围攻击能力有限 | 以单体输出为主——需要其他队友处理大批杂兵 |
| 社交能力弱 | 魅力非核心属性——对话检定依赖队友 |
| 后期成长平滑 | 11级后提升变小——12级仅多一个专长 |
| 对抗远程/飞行敌人 | 需要药水或队友支援才能接近 |

## 核心机制深度解析

### 机制一：巨武器大师 (Great Weapon Master)

这是战斗大师战士的**核心输出专长**：

| 效果 | 详细说明 |
|------|----------|
| **-5命中/+10伤害** | 使用重型双手武器时，可承受-5命中惩罚获得+10伤害。可以手动开启/关闭 |
| **击杀/重击触发附赠攻击** | 用近战武器造成重击或将目标HP降至0时，获得附赠动作额外攻击(每回合仅1次) |

**巨武器大师的数学**：

假设你攻击AC 15的敌人，基础攻击加值为+8(3力量+2熟练+3武器)：

| 模式 | 命中率 | 平均伤害(2d6+3巨剑+3力量) | 期望伤害/次 |
|------|--------|---------------------------|------------|
| 不开GWM | 70%(需投7+) | 2d6+3+3 = 13 | 13 × 0.7 = 9.1 |
| 开GWM | 45%(需投12+) | 2d6+3+3+10 = 23 | 23 × 0.45 = 10.35 |

在这个AC阈值下，开启GWM期望伤害更高。GWM在AC越低时越有价值。

**精准打击的配合**：
精准打击(Precision Attack)消耗1个卓越骰(d8/d10)，在命中掷骰后使用，+1d8/d10到命中。这意味着：

- 如果你投出12(刚好miss AC 15)，精准打击+1d8(平均4.5)=16.5——命中！
- 精准打击可以**在掷骰后决定是否使用**——永远用在差一点就命中的情况下
- 这让GWM的-5惩罚几乎可以无视

### 机制二：战斗大师战技

战斗大师3级获得4个d8卓越骰(短休恢复)，可选择3个战技：

| 战技 | 效果 | 推荐度 | 使用场景 |
|------|------|--------|----------|
| **精准打击 (Precision Attack)** | 命中掷骰+1d8 | ⭐⭐⭐⭐⭐ | 🔑 GWM的核心搭档！在掷骰后使用，把"差点命中"变成"命中" |
| **绊摔打击 (Trip Attack)** | +1d8伤害，目标力量豁免失败则**倒地** | ⭐⭐⭐⭐⭐ | 优先使用——倒地后所有近战攻击获得优势！对高力量敌人成功率低 |
| **反击 (Riposte)** | 敌人未命中你时用**反应**反击，+1d8伤害 | ⭐⭐⭐⭐⭐ | 🔑 唯一的反应输出战技——在敌人回合也能输出！高AC时触发频繁 |
| **缴械打击 (Disarming Attack)** | +1d8伤害，缴械目标武器 | ⭐⭐⭐⭐ | 对持武器敌人极强——缴械后敌人只能用徒手攻击(伤害降低70%+) |
| **恐吓打击 (Menacing Attack)** | +1d8伤害，目标感知豁免失败则**恐惧**(无法靠近你，攻击劣势) | ⭐⭐⭐⭐ | 控制远程/施法者——恐惧下他们无法有效输出 |
| **推撞打击 (Pushing Attack)** | +1d8伤害，推远目标4.5m | ⭐⭐⭐ | 环境击杀专用——悬崖边、熔岩边 |
| **横扫打击 (Sweeping Attack)** | 对目标+另一个附近敌人造成卓越骰伤害(无武器伤害) | ⭐⭐ | 范围伤害有限——不如集中击杀一个目标 |

**5个核心战技推荐**（3级选3个，7级+10级各加选1个）：
1. 精准打击（GWM搭档）
2. 绊摔打击（倒地=优势）
3. 反击（反应输出）
4. 缴械打击（缴械）
5. 恐吓打击（控制）

### 机制三：三重额外攻击 (Improved Extra Attack)

战士11级的标志性能力——攻击动作变为3次攻击：

```
5级之前：攻击动作 = 1次攻击
5-10级：攻击动作 = 2次攻击（额外攻击）
11级+：攻击动作 = 3次攻击（三重额外攻击）

动作如潮+加速后的总攻击数：
11级：
├── 攻击动作：3次
├── 动作如潮：3次
├── 加速额外动作：1次
├── 附赠动作：1次（GWM击杀触发或PAM附赠）
└── 总计：7-8次攻击
```

## 种族选择

### 主推：半兽人 (Half-Orc)

| 种族特性 | 效果 | 价值评估 |
|----------|------|----------|
| **凶蛮攻击 (Savage Attacks)** | 近战武器重击时，额外多投一个武器伤害骰。对巨剑来说=额外1d6(正常重击从2d6→4d6=3d6+1d6)。 | ⭐⭐⭐⭐⭐ 🔑 重击时伤害大幅提升。配合巨武器(2d6基础)，重击=5d6而非4d6 |
| **不屈 (Relentless Endurance)** | HP降至0时改为降至1(1次/长休) | ⭐⭐⭐⭐⭐ 免费复活一次——在新手或不小心的战斗中极其重要 |
| **威吓熟练** | 威吓技能熟练 | ⭐⭐ 对话选项更多 |
| **黑暗视觉** | 12m | ⭐⭐⭐⭐ |

半兽人的凶蛮攻击与战斗大师的重击协同极好——人类定身术(队友施放)=麻痹=近战自动重击=4d6+1d6(半兽人)+卓越骰重击=巨大伤害。

### 备选种族

| 种族 | 亮点 | 权衡 |
|------|------|------|
| **黄金矮人 (Gold Dwarf)** | 毒素抗性+体质+2，HP更高 | 无重击加成——输出不如半兽人 |
| **吉斯洋基 (Githyanki)** | 免费迷踪步+中甲熟练+星界知识(任意技能熟练) | 极好的机动性和灵活性——迷踪步弥补了战士的机动短板 |
| **木精灵 (Wood Elf)** | 移动速度10.5m+察觉熟练 | 更好的机动性和感知——但战士不需要察觉熟练？好过没有 |
| **人类 (Human)** | 全技能+1 | 对话和技能检定更强——平衡选择 |

## 专长选择

### 专长详细分析

| 等级 | 专长 | 效果 | 选择理由 |
|------|------|------|----------|
| 战士4 | **巨武器大师 (Great Weapon Master)** | 切换开关：重型武器-5命中/+10伤害；击杀/重击获得附赠攻击 | 🔑 本构建**伤害核心**。+10伤害与三重额外攻击(3次)叠加=每回合+30伤害。精准打击弥补-5惩罚 |
| 战士6 | **ASI 力量+2** | 力量17→**19** (+4) | 主属性提升，+1命中/+1伤害 |
| 战士8 | **警觉 (Alert)** | 先攻+5，免疫突袭 | 战士敏捷低(10)，先攻仅为+0。警觉+5让你先出手——先杀敌=减少敌人行动=更高生存力 |
| 战士12 | **凶蛮打手 (Savage Attacker)** | 每次近战武器攻击的伤害骰重投一次，取较高者 | 🔑 对巨剑(2d6)每次攻击重投伤害骰=每次攻击期望伤害从7提升至约8.37——提升约20%基础武器伤害。叠加半兽人重击=5d6全部重投 |

### 凶蛮打手的数学

```
巨剑(2d6)伤害骰分布：
正常2d6：平均 = 7
重投取高：每次投掷2次2d6，取较高者
效果：将低伤害(2-5)的概率大幅降低，高伤害(8-12)的概率大幅提升

粗略估算：凶蛮打手约提升巨剑基础伤害20-25%
每次攻击：2d6从平均7→约8.4，提升1.4/次
3次攻击/回合：提升约4.2/回合
加上GWM击杀的附赠攻击：提升更多
```

### 未选择的重要专长

| 专长 | 为何不选 |
|------|----------|
| **长柄武器大师 (Polearm Master)** | PAM的附赠攻击(1d4)与GWM的附赠攻击(从击杀/重击)冲突——GWM附赠攻击是完整的武器攻击(2d6+15)，远胜PAM的1d4。且PAM需要长柄武器(1d10)，伤害骰低于巨剑(2d6) |
| **哨兵 (Sentinel)** | 强大的控制专长——但战斗大师已经有反击(反应输出)，哨兵需要竞争宝贵的反应。12级时战士有4个专长，如果有多余专长可以考虑 |
| **高等武器大师 (Great Weapon Fighting style)** | 这是战斗风格，不是专长——已在1级选择 |
| **中等护甲大师 (Medium Armor Master)** | 战士使用重甲，不需要 |

## 完整升级路线：逐级详细拆解

### 第1级：战士1

```
职业：战士1
生命骰：1d10 + 3(体质) = 13 HP
熟练加值：+2
```

**获得的能力**：

| 能力 | 类型 | 详细说明 |
|------|------|----------|
| **战斗风格：巨武器战斗 (Great Weapon Fighting)** | 战士1 | 🔑 使用双手近战武器时，伤害骰出1或2时重投一次(取第二次结果，即使仍是1或2)。对巨剑(2d6)极其有价值——2d6的期望从7提升至约8.33 |
| **第二口气 (Second Wind)** | 战士1 | 附赠动作回复1d10+1 HP，短休恢复。1级额外13HP/短休的生存能力 |
| **重甲熟练** | 战士1 | 所有重甲熟练 |
| **盾牌熟练** | 战士1 | 盾牌+2 AC |

**巨武器战斗风格数学**：

```
巨剑(2d6)伤害变化：
正常2d6：平均 = 7.0
巨武器风格(1和2重投)：
每个d6：1和2重投(第二次期望仍为3.5)
新期望：2/6×(3.5) + 4/6×[(3+4+5+6)/4] = 1.17 + 4/6×4.5 = 1.17 + 3 = 4.17
2d6新期望：2 × 4.17 = 8.33

提升：8.33 - 7.0 = +1.33 伤害/次(提升约19%)
```

**战斗策略(1级)**：
- 获得永燃之刃(Everburn Blade)——从鹦鹉螺号飞船的指挥官扎尔克(Zhalk)身上获得
- 永燃之刃：2d6+1d4火焰巨剑——1级时约14伤害/次
- 第二口气提供额外生存力
- 附赠动作目前没有固定用途

**装备目标**：
- 🔑 永燃之刃（鹦鹉螺号飞船序章获得）
- 重甲——越快越好（链甲AC 16起）
- 如果没拿到永燃之刃——任意巨剑/巨斧


**获得的能力**：

| 能力 | 类型 | 详细说明 |
|------|------|----------|
| **战斗大师子职 (Battle Master)** | 子职业 | 获得4个d8卓越骰(短休恢复)。3个已知战技 |
| **卓越骰 (Superiority Dice)** | 子职业 | 4个d8，短休恢复。用于战技的额外效果 |

**推荐战技(3级选3个)**：

| 战技 | 理由 |
|------|------|
| **精准打击 (Precision Attack)** | 🔑 GWM搭档——在掷骰后使用，把"差1-4点命中"变成命中 |

**战斗策略(3级)**：

```
3. 优先使用绊摔打击→目标倒地→后续攻击有优势
4. 击杀触发GWM附赠攻击→额外1次巨武器攻击
5. 敌人回合miss你→反应反击→额外1次巨武器攻击
```

```

```

**获得的能力**：

| 能力 | 类型 | 详细说明 |

| **新战技** | 子职业 | 可替换1个已知战技(通常不需要) |

**GWM的实际应用**：

```
AC阈值指南(力量17, 熟练+2, 武器+1)：
基础攻击加值：+2(熟练)+3(力量)+1(武器)=+6
开启GWM：+1

对AC 13敌人(命中率45% vs 70%)：应开GWM
对AC 16敌人(命中率30% vs 55%)：看情况——有精准打击时开
对AC 19敌人(命中率15% vs 40%)：应关GWM

简化记忆：
- 杂兵(AC≤14)：GWM全程开
- 中等敌人(AC 15-17)：有优势(倒地/夹击)时开，配合精准打击
- 重甲boss(AC 18+)：关GWM，或只在对倒地目标时开
```

## 战斗轮换

### 标准回合（每回合）

```
阶段1：移动
├── 向最近的威胁目标移动
├── 优先接近施法者(打断专注)或高伤害远程
├── 如有迷踪步(靴子/护符) → 直接传送到施法者身边
└── 利用跳跃(力量越高跳越远)跨越障碍

阶段2：攻击动作(3次攻击，11级)
├── 攻击1：绊摔打击(Trip Attack)
│   └── 目标力量豁免(DC = 8+4(熟练)+5(力量)=DC 17) → 失败则倒地
│   └── 伤害：2d6+5(力量)+10(GWM)+1d10(战技)+3(武器) = 约31
│
├── 攻击2：缴械打击(Disarming Attack) 或 直接GWM攻击
│   └── 如果攻击1已倒地 → 攻击2获得优势！
│   └── 缴械施法者=他们的法术成分法器掉落
│   └── 伤害同上(如果使用战技)
│
├── 攻击3：直接GWM攻击 或 恐吓打击(Menacing Attack)
│   └── 如果目标已倒地 → 优势攻击
│   └── 伤害：2d6+5+10+3 = 约25(无战技)
│
└── GWM附赠：如果击杀或重击 → 额外1次攻击

阶段3：附赠动作
├── 如果没有触发GWM附赠 → 喝药水(巨像灵药)或第二口气
├── 战斗中也可用迷踪步(靴子)调整位置
└── 或激活特殊武器能力(如有)
```

## 常见问题与误区

:::danger 误区：GWM应该一直开着
GWM的-5命中惩罚在面对高AC敌人时可能让你完全打不中。一般规则：
- AC ≤ 16：GWM全程开
- AC 17-19：只有攻击有优势时开(倒地目标、夹击、祝福术)
- AC ≥ 20：关闭GWM，或只在精准打击可用时开

简单原则：如果你在上回合miss了大多数攻击→关GWM。如果命中>60%→开GWM。
:::

:::warning 关于巨斧 vs 巨剑
巨剑(2d6)和巨斧(1d12)的期望：
- 巨剑：2d6 = 7 平均(配合GWF=8.33)
- 巨斧：1d12 = 6.5 平均(配合GWF≈7.33)

巨剑更稳定(集中分布在中段)，巨斧更波动(更大的重击骰——2d12 vs 4d6)。配合半兽人，巨斧的重击(2d12+1d12=3d12=19.5) vs 巨剑(4d6+1d6=5d6=17.5)略高。但常规攻击中巨剑期望更高(GWF加成更好)。

**推荐：巨剑用于常规输出，巨斧如果你偏向重击build。**
:::

:::tip 精准打击的最佳用法
1. 在掷骰后使用(不是掷骰前！)
2. 只有在差1-5点命中时才使用
3. 不要浪费在"差太多肯定不中"或"本身就能命中"的情况下
4. 保留至少1个卓越骰用于关键时刻
5. 精准打击与GWM是绝配——每个d10精准打击约等于7-10点额外期望伤害
:::

## 总结

战斗大师战士是BG3中最经典、最可靠、最强的纯近战物理输出。纯战士12级无需兼职的简洁性，加上战斗大师战技的战术深度，让这个构建适合任何玩家。

**核心游戏计划**：
1. 接近目标（迷踪步/跳跃）
2. 攻击动作3次GWM巨剑攻击
3. 绊摔打击优先（倒地=优势）
4. 精准打击补命中（GWM惩罚抵消）
5. 反击利用反应（额外攻击）
6. Boss战动作如潮+加速=7+次GWM攻击

**装备核心**：
- 永燃之刃(1章)→银剑(2章)→博德安巨人杀手(3章)
- 阿达曼重甲(1章)→持久甲(3章)
- 致命一击戒指(攻击优势)
- 高等生命护符(体质23=生存质变)

**适合人群**：
- 新手玩家——最简单的操作，最高的容错
- 喜欢近战砍杀的玩家——刀刀到肉
- 想要高输出的玩家——三重额外攻击无人能及
- 不想管理法术位的玩家——战技比法术简单10倍
