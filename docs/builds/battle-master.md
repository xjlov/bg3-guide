# 战斗大师战士 (Battle Master Fighter)

**新手最佳选择** — 纯战士12级无需兼职，操作直观、输出稳定、容错极高。巨武器大师 + 战斗大师战技 = 每回合稳定的高额近战伤害。

***

## 核心机制

战斗大师子职获得**卓越骰（Superiority Dice）**——d8骰子(后期d10)，可用于发动多种战技，核心输出战技：

- **精准打击（Precision Attack）**: 命中检定+1d8，专门抵消巨武器大师的-5命中惩罚
- **绊摔打击（Trip Attack）**: 额外1d8伤害 + 目标力量豁免失败则倒地
- **缴械打击（Disarming Attack）**: 额外1d8伤害 + 缴械目标武器
- **反击（Riposte）**: 敌人未命中时用反应攻击，额外1d8伤害

配合**巨武器大师(Great Weapon Master)**专长——使用重型双手武器时获得-5命中/+10伤害惩罚，击杀或重击时获得附赠动作额外攻击。精准打击直接弥补命中惩罚，使+10伤害几乎无代价触发。

战士11级的**三重额外攻击(Improved Extra Attack)**使每轮3次主动攻击，这是其他任何职业无法达到的基础攻击次数。

## 战斗循环

**战斗前:**
1. 装备双手巨剑/巨斧、重甲
2. 确保队伍中有加速术施法者支撑

**标准回合:**
1. 判断敌人AC — AC低于16直接巨武器大师全开
2. AC高于18的敌人使用**精准打击**抵消-5惩罚
3. **绊摔打击**优先 — 倒地后后续攻击获得优势
4. 巨武器大师击杀触发 → **附赠动作额外攻击**

**爆发回合 (动作如潮 + 加速):**
1. 加速 → 主动动作 = 3次攻击 (Lv11)
2. 动作如潮 → 额外动作 = 3次攻击
3. 加速额外动作 = 1次攻击
4. 总计 **7次巨武器大师攻击**，其中穿插精准打击/绊摔打击
5. 击杀触发附赠攻击 → 最多8次
6. 理想伤害: 7× (2d6+5+10) = 7×22 ≈ **154+伤害** (不含战技骰和附魔)
