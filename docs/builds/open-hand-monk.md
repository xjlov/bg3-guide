# 散打武僧 (Open Hand Monk)

**版本T0 DPS天花板** — 利用酒馆殴斗者专长 + 力量灵药 + 多段徒手攻击，实现单回合爆发全游戏最高。

***

## 核心机制

散打宗武僧的「震荡拳」「推掌」「震慑拳」配合**酒馆殴斗者（Tavern Brawler）**专长——徒手和无武装攻击获得力量调整值的**双倍**加值，使每拳的命中和伤害加成翻倍。通过饮用**山丘巨人力量灵药**（力量固定21），武僧不再需要自身投资力量，可将购点全部投入敏捷、体质和感知。

盗贼(盗贼子职)3级提供**额外附赠动作**，配合武僧的「灵巧移动」，每回合可打出 **2次主动攻击 + 2次附赠徒手打击**（加速后更多），每拳享受双倍力量加值。

## 战斗循环

**战斗前:**
1. 饮用山丘巨人力量灵药 (每日长休前)
2. 上满血触发移位披风

**标准回合 (无加速):**
1. **附赠动作1** — 灵巧移动：徒手打击(触发力量双倍加值)
2. **附赠动作2** (盗贼) — 徒手打击/震荡拳
3. **主动攻击1** — 徒手打击
4. **主动攻击2** — 震慑拳 (目标体质豁免，失败则震慑一轮)

**爆发回合 (加速+动作如潮):**
- 加速后获得额外主动动作 → 最多 **6次主动攻击 + 2次附赠打击 = 8段输出**
- 每次命中附带1d10力场(手套) + 1d4+感知(灵体) + 双倍力量 + 武道骰
