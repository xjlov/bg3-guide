## 新手推荐路线

- **第一次玩?** → [战斗大师](/builds/battle-master) — 纯战士12级，操作简单，输出稳定
- **想要简单强?** → [投掷野蛮人](/builds/throw-barbarian) — 投掷秒杀，无需复杂站位
- **追求极限DPS?** → [散打武僧](/builds/open-hand-monk) — 当前版本单回合最高爆发
- **喜欢施法?** → [风暴术士](/builds/storm-sorcerer) — 大范围超高法术伤害
- **想要全能?** → [剑舞诗人](/builds/swords-bard) — 远程输出+控制+对话技能拉满
