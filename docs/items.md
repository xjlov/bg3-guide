## 精金熔炉锻造指南

精金熔炉位于第一章幽暗地域，打败Boss格鲁姆后可锻造2件精金装备（只有2块秘银矿）：

| 模具 | 产出 | 推荐 |
|------|------|------|
| 板甲模具 | 精金板甲（AC18, 免疫暴击） | ⭐⭐⭐ 优先 |
| 鳞甲模具 | 精金鳞甲（AC16, DEX+2上限） | ⭐⭐ |
| 盾牌模具 | 精金盾牌 | ⭐⭐ |
| 长剑模具 | 精金长剑 | ⭐ |
| 钉头锤模具 | 精金钉头锤 | ⭐ |

推荐锻造方案：**精金板甲 + 精金盾牌**（重甲角色），或**精金鳞甲×2**（敏系角色）。

## 装备获取技巧

- 商人每长休/角色升级刷新商品
- 按住 Alt 键高亮可拾取物品
- 大部分Boss掉落传说装备**每局唯一**，错过无法再得
- 盗窃商店装备需要：高巧手 + 隐身药水 + 回合制模式
