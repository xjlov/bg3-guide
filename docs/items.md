# 装备图鉴

博德之门3拥有海量的魔法装备系统。本板块整理了游戏中最值得关注的核心装备。

## 装备稀有度

| 稀有度 | 颜色 | 描述 |
|--------|------|------|
| **普通** | 白 | 基础装备，无魔法属性 |
| **精良** | 绿 | +1附魔，附带1个魔法效果 |
| **稀有** | 蓝 | +1~2附魔，附带2个魔法效果 |
| **极稀有** | 紫 | +2附魔，附带2~3个强力效果 |
| **传说** | 金 | +3附魔，附带3+独特强力效果 |

## 装备分类

### 武器
- **军用武器**：需特定熟练项，伤害更高
- **简易武器**：大多数职业默认熟练
- **远程武器**：弓、弩、手弩
- **法器**：法杖、权杖等施法工具

### 护甲
- **布甲**：10 + 敏捷调整值
- **轻甲**：11~12 + 敏捷调整值
- **中甲**：13~16 + 敏捷调整值（最高+2）
- **重甲**：14~19（敏捷不计入AC）

### 饰品
- 披风、头盔/帽子、手套、靴子、护符、戒指（2格）

## 装备获取技巧

- **商人刷新**：每长休/角色升级后刷新商品
- **商人好感**：给予金币提升好感度
- **特殊掉落**：部分Boss掉落的装备唯一，错过不可再得
- **锻造系统**：精金熔炉可锻造2件精金装备
- **盗窃**：高巧手+隐身可偷取商店贵重装备

:::warning
大部分Boss掉落的传说装备为每局唯一，不慎卖店无法再次获取。
:::
