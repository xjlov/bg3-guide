# 战斗机制详解

理解博德之门3的战斗系统是从入门到精通的关键。本指南覆盖行动经济、地形利用、潜行机制和团队协同。

***

## 行动经济 (Action Economy)

每回合，每个角色拥有以下行动资源：

| 资源 | 数量 | 用途 |
|------|------|------|
| **动作 (Action)** | 1 | 攻击、施法、疾走、脱离等 |
| **附赠动作 (Bonus Action)** | 1 | 潜行、跳跃、推击、部分法术等 |
| **反应 (Reaction)** | 1 | 借机攻击、护盾术、法术反制等 |
| **移动 (Movement)** | 约9m | 走位、跳跃 |

### 加速手段（扩展行动经济）

- **加速术**：额外获得1个动作（限攻击/疾走/脱离/躲藏）
- **动作如潮**（战士2级）：额外获得1个动作
- **嗜血灵药**：击杀后获得额外动作
- **盗贼3级（快速之手）**：额外获得1个附赠动作（手弩射手核心）
- **速度药水**：3回合加速效果

:::tip 最强行动组合

战士11级（三重攻击）+ 加速术 + 动作如潮 + 嗜血灵药 + 弓术风格 = **一回合10+次攻击**

:::

## 地形与高低差

### 高地优势

- 从**高处攻击低处**：攻击骰+2优势
- 从**低处攻击高处**：攻击骰劣势

### 地形杀伤

- **推击/雷鸣波**：将敌人推下悬崖/深渊即死
- **火油/烟粉桶**：引爆地面可燃物造成AoE伤害
- **冰面**：降低移动速度，可能摔倒（敏捷豁免）
- **蛛网/藤蔓**：束缚目标

***

## 潜行与突袭轮

### 触发突袭轮

1. 隐匿状态下（按住C蹲下）接近敌人
2. 在红色视野区外发起攻击
3. 突袭成立 → 敌人第一轮无法行动
4. 突袭轮**所有攻击均为优势**

:::info 突袭轮的价值

突袭轮是最高效的清场方式。配合刺客3级（突袭轮自动重击），可在敌方行动前消灭关键目标。

:::

## 团队协同组合技

### 潮湿 + 闪电/冰霜（双倍伤害）

1. 施放造水术/投掷水瓶 → 目标获得「湿润」
2. 施放闪电法术 → **双倍伤害**
3. 连锁闪电 + 潮湿 = 最强AoE组合

### 击倒 + 近战（攻击优势）

1. 推击/拌摔攻击/油腻术击倒目标
2. 倒地状态：近战攻击优势
3. 战士 → 拌摔攻击 → 动作如潮 → 全力输出

### 定身术 + 攻击（自动重击）

1. **人类定身术**/怪物定身术定住目标
2. 5英尺内攻击**必定重击**
3. 至圣斩 + 重击 = 伤害炸裂

### 黑暗术 + 魔鬼视界

1. 用黑暗术覆盖战场（或黑暗箭矢）
2. 魔鬼视界（邪术师魔能祈唤）可在黑暗中正常视物
3. 你在黑暗中对敌人攻击优势；敌人攻击你劣势

***

## 油桶/烟粉桶战术 (Barrelmancy)

博德之门3的物理引擎允许极端的「桶战术」：

1. 收集烟粉桶/油桶（第一章地精营地大量）
2. 在Boss脚下堆放
3. 远离 → 火球/火焰箭引爆
4. 瞬间巨额伤害（可秒杀大部分Boss）

:::warning 注意事项

- 桶的重量占用负重，需力量角色携带
- 堆叠桶可被敌人发现（影响对话）
- 荣誉模式中部分Boss免疫即死

:::
