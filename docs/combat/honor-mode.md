# 荣誉模式完全攻略

荣誉模式是博德之门3的最高难度挑战：**单一存档、传奇行动、死亡删档**。本攻略帮助你在高难度下安全通关。

***

## 荣誉模式变化一览

| 改动 | 说明 |
|------|------|
| **单一存档** | 无法SL（保存/读档）；死亡后可选「继续」但无法获得骰子皮肤 |
| **传奇行动** | 所有主要Boss新增传奇反击技能 |
| **加速术削弱** | 加速术额外动作仅限1次攻击（非完整动作链） |
| **附伤削弱** | 部分附伤机制（如酒馆殴斗者）不再叠加 |
| **禁止SL** | 对话检定失败必须接受结果 |
| **死亡=删档** | 全队阵亡后荣誉模式存档被删除（可选择继续降为自定义难度） |

## 推荐配队

### 核心位置

| 角色 | 职业/Build | 职责 |
|------|-----------|------|
| **主角** | 剑舞诗人10/战士2 或 风暴术士 | 对话（高魅力）+ 爆发输出 |
| **坦克/辅助** | 光明牧师12（影心） | 群体治疗、守护之链、光耀伤害 |
| **物理输出** | 投掷野蛮人5/游荡者3/战士4（卡菈克） | 酒馆殴斗者投掷流 |
| **控制/爆发** | 风暴术士12（盖尔）或 散打武僧（莱埃泽尔） | AoE/单体爆发 |

### 最佳8人轮换

将不常用的队友留在营地作为**增益工具人**：
- **营地牧师**：施放守护之链（伤害转嫁）、行动自如、死亡守护、援助术（全员生命上限+5/10/15）
- **营地德鲁伊**：酿造灵药、施展大步奔行
