# 战斗速查手册

本页汇总了战斗中常用公式、数据和规则速查表。

***

## AC（防御等级）公式

| 护甲类型 | AC公式 |
|----------|--------|
| 无护甲（武僧/野蛮人） | 10 + 敏捷 + 感知（武僧）/体质（野蛮人） |
| 布甲 | 10 + 敏捷 |
| 轻甲 | 护甲基础AC + 敏捷（无上限） |
| 中甲 | 护甲基础AC + 敏捷（最多+2；中甲大师专长+3） |
| 重甲 | 护甲基础AC（敏捷加成不计入） |
| 法师护甲 | 13 + 敏捷 |
| 持盾 | AC +2（普通盾）/ +3（+1盾等） |

***

| 等级 | 熟练加值 |

## 常见状态

| 状态 | 效果 |
|------|------|
| **目盲** | 攻击劣势；被攻击优势 |
| **倒地** | 近战对其优势；远程攻击劣势；站立消耗半速 |
| **麻痹** | 无法行动；5英尺内攻击**必定重击**；敏捷/力量豁免自动失败 |
| **束缚** | 速度归零；攻击劣势；敏捷豁免劣势 |
| **魅惑** | 无法攻击魅惑者；魅力施法者对其优势 |
| **恐慌** | 无法移动；攻击劣势；能力检定劣势 |
| **震慑** | 同麻痹（无法行动、自动重击） |
| **中毒** | 攻击劣势；能力检定劣势 |
| **沉睡** | 无法行动；受到伤害后苏醒 |
| **加速** | +2 AC；敏捷豁免优势；额外动作 |
| **湿润** | 闪电/冰霜伤害加倍；火焰伤害减半 |
| **集中** | 维持某些法术（受伤害需体质豁免打断） |
