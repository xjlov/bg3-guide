# 任务攻略

全三章主线流程。关键抉择、隐藏物品、可错过内容。

## 章节总览

| 章节 | 区域 | 等级 | 核心内容 |
|------|------|------|----------|
| 序章 | 螺壳舰 | 1 | 逃离飞船、救影心、永燃之刃 |
| 第一章 | 荒野/幽暗地域 | 1-7 | 德鲁伊林地、地精营地、精金熔炉、养育间 |
| 第二章 | 暗影诅咒之地 | 6-8 | 旅店保卫战、莎尔试炼、米尔寇 |
| 第三章 | 博德之门 | 8-12 | 钢铁王座、希望之邸、巴尔神殿、虚空脑 |

## 第一章推荐路线

1. 螺壳舰 → 坠机海滩(搜刮+收队友) → 德鲁伊林地(任务中心)
2. 染疫村落 → 地精营地(三首领) → 晋升之路(卡菈克)
3. 沃金休眠地(限时) → 沼泽鬼婆 → 幽暗地域(四入口)
4. 精金熔炉 → 山隘/养育间 → 进入第二章

## 进入第二章

通过山隘(养育间出口)或幽暗地域电梯。进入后不可返回第一章。
