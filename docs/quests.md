# 任务攻略

本板块涵盖博德之门3从序章到终章的全部主线与重要支线任务流程，按章节组织，确保你不遗漏关键内容。

## 章节总览

| 章节 | 区域 | 推荐等级 | 核心内容 |
|------|------|----------|----------|
| **序章** | 螺壳舰 (Nautiloid) | 1 | 逃出螺壳舰、招募影心、指挥官扎尔克 |
| **第一章** | 荒野/地精营地/幽暗地域 | 1-7 | 德鲁伊林地、地精三首领、养鸡人养育间 |
| **第二章** | 影界诅咒之地 | 5-9 | 旅店保卫战、月出之塔、莎尔试炼、凯瑟里克 |
| **第三章** | 博德之门下城区 | 8-12 | 钢铁王座、希望之邸、主脑决战 |

## 推荐路线

**新手推荐：**
1. 序章 → 海滩 → 德鲁伊林地（集散中心）
2. 染疫村庄 → 地精营地（三首领）
3. 晋升之路 → 沃金休眠地（限时救援）
4. 沼泽/茶室 → 鬼婆支线
5. 幽暗地域（四条入口任选）
6. 精金熔炉（锻造精金装备）
7. 山隘 → 养育间
8. 进入第二章

**速通路线：** 直奔山隘 → 养育间拿洛山达之血 → 第二章 → 月出之塔 → 莎尔试炼 → 第三章。

## 核心技巧

### 多存档

- 重要抉择前**务必手动存档**（F5快速存档，F8快速读档）
- 保留关键节点的存档，方便回溯不同剧情分支
- 荣誉模式只有一个存档位，死亡即删档

### 区域探索

- **进入下一章前**确保当前区域充分探索，部分任务会因章节推进而失效
- 每次长休前检查是否有待触发营地剧情
- 小地图上的黄色标记为未完成的任务目标

### 资源管理

- 营地补给前期紧张，多搜刮食物（可按住Alt高亮物品）
- 商人每长休/升级后刷新商品
- 金币紧缺时可将垃圾装备卖给不同商人（提升好感后打折）

### 对话技巧

- 对话中的 **`[属性]` 检定**取决于骰子结果，高魅力角色更有优势
- 带有 **`[职业]`** 或 **`[种族]`** 标识的对话选项往往提供独特剧情
- 使用「交友术」或「魅惑人类」可大幅降低交涉难度

:::tip 章节过渡警告

当你准备从第一章进入第二章（通过山隘或幽暗地域电梯），或从第二章进入第三章时，游戏会弹出确认提示。**确认前请检查是否已完成当前章节的所有重要任务**。

:::

### 第一章 → 第二章 过渡

- 通过山隘：进入**山隘**区域（养育间），然后从山隘出口进入影界诅咒之地
- 通过幽暗地域：乘坐精金熔炉区域的**电梯**到达影界诅咒之地

### 第二章 → 第三章 过渡

- 击败凯瑟里克/米尔寇后，跟随主线前往**博德之门郊外**，经过吉斯洋基伏击战后进入下城区。

:::danger 一次性/限时内容

以下内容在第一章推进后**不可返回**：

- 螺壳舰上的永燃之刃（指挥官扎尔克掉落）
- 沃金休眠地的限时救援（触发后必须立即完成，否则NPC死亡）
- 德鲁伊林地封锁任务（长休次数过多会导致林地自动封锁）

:::
