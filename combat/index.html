🎲 骰子模拟器

数量：1加值：+0

动作经济​

资源每回合最佳用法
动作1次攻击 · 施法 · 疾走 · 推击
附赠动作1次跳跃 · 喝药 · 副手攻击 · 推击
移动~9m可拆分：移动→攻击→再移动
反应1次/轮借机攻击 · 法术反制 · 护盾术

加速术 = 额外动作。动作如潮（战士2级）= 再+1动作。嗜血灵药 = 击杀后+1动作。三叠加 → 一回合 7 次攻击。

五大团队连招​

连招组合效果
湿润 + 闪电造水术 + 闪电束闪电伤害 ×2
定身 + 近战人类定身术 + 巨武器5尺内自动暴击
黑暗 + 魔鬼视界黑暗术 + 恶魔视界敌人劣势，你优势
倒地 + 猛击绊摔打击 + 巨武器大师倒地后后续优势
推下悬崖雷鸣波 + 推击无视血量秒杀

环境战术​

技巧操作
高地打低地命中+2，远程射程翻倍
油桶 + 火焰堆叠油桶→火焰箭引爆→巨额 AOE
水 + 电投水湿润→闪电箭→全屏触电
冰面敌人移动可能滑倒（倒地）
卡门战术占据门口/窄道，敌人只能一个个进

荣誉模式​

  • 单存档，死亡删档
  • 所有 Boss 获得传奇动作
  • 加速术只给 +1 攻击
  • 酒馆殴斗者伤害加成减少
