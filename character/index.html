角色创建深度指南

起源选择​

角色创建的第一步是选择起源，这决定了你在费伦大陆上的身份定位。

起源类型说明推荐人群
自定义起源完全自由的种族、职业、背景组合。可自定义外貌与姓名。所有玩家（推荐）
预设起源角色扮演影心、盖尔、阿斯代伦等6位起源队友，有独特剧情对话。二周目玩家
邪念（Dark Urge）失忆的独特起源，有黑暗冲动。可自定义种族职业，但剧情极为黑暗。追求深度故事的玩家

新手建议： 一周目选「自定义起源」，二周目体验「邪念」。预设起源角色更适合已经熟悉游戏的玩家。

种族选择（11种族详解）​

BG3 共包含 11 个可选种族，每个种族拥有独特的天赋能力和属性加成。

种族核心特性推荐职业
人类多才多艺：额外技能熟练项，负重+25%。民兵武器熟练。全职业通用
精灵（高等/木）敏锐感官：察觉熟练。黑暗视觉。魅惑豁免优势，免疫魔法睡眠。木精灵移动速度+1.5m。游侠、德鲁伊、游荡者
卓尔（席尔德林/罗丝）卓越黑暗视觉（24m）。精灵血统。自带妖火与黑暗术。游荡者、术士、邪术师
半精灵（高等/木/卓尔）黑暗视觉。民兵武器熟练（高等/木）。额外2个技能熟练。圣武士、吟游诗人、术士
半兽人凶蛮攻击：暴击多一骰。顽强不屈：首次倒地改为1血。威吓熟练。野蛮人、战士、圣武士
矮人（盾/金/灰）矮人韧性：毒素伤害抗性。黑暗视觉。盾矮人中甲熟练，灰矮人自带隐形与变巨术。战士、牧师、圣武士
半身人（轻足/壮心）幸运：攻击检定出1时重投。勇者无畏：恐慌豁免优势。轻足半身人可隐匿躲藏。游荡者、游侠、吟游诗人
侏儒（森林/岩石/地底）侏儒狡黠：智/感/魅魔法豁免优势。地底侏儒卓越黑暗视觉。法师、奇术师、德鲁伊
提夫林（阿斯莫德斯/梅菲斯特/扎瑞尔）地狱火抗性。黑暗视觉。各亚种获得不同戏法（奇术/法师之手/奇效术）。邪术师、术士、吟游诗人
吉斯洋基人星界知识：自选技能熟练（可长休更换）。法师之手（隐形）。自带迷踪步与跳跃术。中甲熟练。战士、法师、武僧
龙裔龙族吐息：依血统造成元素伤害。对应元素抗性。无黑暗视觉。圣武士、术士、战士

27点购点系统​

BG3 使用 27点购点制 决定初始属性。每项属性起始为 8，购买到 13 花费 1:1，14-15 花费 1:2。

推荐配点方案​

方案一：力战蛮（力量近战）

  • 力17 / 敏14 / 体15 / 智8 / 感10 / 魅8 → 剩余0点
  • 种族选半兽人（+2力 +1体）→ 最终 力18 体16

方案二：敏系游荡/游侠（敏捷远程）

  • 力8 / 敏17 / 体14 / 智10 / 感14 / 魅10 → 剩余0点
  • 种族选木精灵（+2敏 +1感）→ 最终 敏19 感14

方案三：魅力施法者（术士/邪术/诗人）

  • 力8 / 敏14 / 体15 / 智8 / 感10 / 魅17 → 剩余0点
  • 种族选半精灵（+2魅 +1敏 +1体）→ 最终 魅19 体16

方案四：法师/智力职业

  • 力8 / 敏14 / 体14 / 智17 / 感10 / 魅10 → 剩余0点
  • 种族选侏儒（+2智 +1敏）→ 最终 智18 敏14

背景技能熟练灵感触发条件
侍僧洞悉、宗教遵循信仰/帮助宗教机构
骗子欺瞒、巧手通过诈骗获利
罪犯隐匿、巧手犯罪/盗窃成功
艺人体操、表演娱乐/吸引观众
平民英雄驯兽、求生帮助弱者/保护平民
公会工匠洞悉、游说商业谈判/工匠技艺
隐士医药、宗教发现秘密/独自调查
贵族历史、游说利用身份/展示贵族风范
化外之民运动、求生野外生存/追踪
智者奥秘、历史获得知识/解开谜题
士兵运动、威吓战术胜利/服从指挥
流浪儿巧手、隐匿城市生存/帮助流浪者

推荐技能​

  • 察觉（感知）：全游戏最重要的技能，发现陷阱、隐藏物品、环境细节
  • 游说/欺瞒/威吓（魅力）：社交三件套，影响大量对话结果
  • 巧手（敏捷）：开锁、解除陷阱，团队必有一人点满
  • 隐匿（敏捷）：潜行偷袭配合
创建思路
  • 确保队伍覆盖 察觉+巧手+社交 三大核心
  • 智力技能（奥秘/历史/宗教/调查）对任务对话很有帮助
  • 不要忽视运动（力量）—— 推人、跳跃、抵抗推击都靠它
