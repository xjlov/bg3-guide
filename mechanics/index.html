核心战斗机制

博德之门3 基于 龙与地下城第5版（D&D 5E） 规则，并在电子游戏化过程中做了若干调整。理解这些机制是掌握战斗的关键。

D20 系统​

BG3 的几乎所有判定都通过 投1颗20面骰（D20）+ 调整值 ≥ 目标难度等级（DC） 来决定成功与否。

公式：1d20 + 属性调整值 + 熟练加值 + 其他加值

判定类型用途关键调整值来源
攻击检定命中敌人力量（近战）/ 敏捷（远程/灵巧） + 熟练加值
属性检定对话、探索、技能对应属性 + 技能熟练（如有）
豁免检定抵抗法术/陷阱豁免属性 + 熟练（如有）

出20必中，出1必失 —— D20的绝对法则。无论AC多高，命中骰出20必定命中（且暴击），出1必定失手。

属性值与调整值​

6大属性决定角色的基础能力。调整值 = (属性值 - 10) / 2（向下取整）。

属性英文影响内容关键技能
力量 STRStrength近战命中/伤害、跳跃距离、负重、推击运动
敏捷 DEXDexterity远程/灵巧命中、AC加成、先攻、反射豁免体操、巧手、隐匿
体质 CONConstitution生命值（HP）、专注豁免—
智力 INTIntelligence法师施法、调查判定奥秘、历史、调查、宗教
感知 WISWisdom牧师/德鲁伊/游侠施法、察觉驯兽、洞悉、医药、察觉、求生
魅力 CHACharisma诗人/圣武士/术士/邪术师施法、交易价格欺瞒、威吓、表演、游说

优劣势系统​

优势（Advantage）：投两次D20，取较高值。统计学约等效 +5 加成。 劣势（Disadvantage）：投两次D20，取较低值。统计学约等效 -5 惩罚。

优劣势不叠加。拥有多个优势来源也只投两次，一个劣势就足以抵消所有优势（无论数量）。

常见优势来源​

  • 攻击处于倒地或目盲状态的敌人
  • 从隐藏状态发起攻击
  • 攻击时处于高处（远程）
  • 受到祝福术、精灵之貌等法术增益

常见劣势来源​

  • 远程攻击处于近战威胁范围内的敌人
  • 在黑暗中攻击（无黑暗视觉时）
  • 受到致盲、中毒、恐慌等状态
  • 攻击倒地状态的目标（远程）

动作经济​

每回合角色拥有以下资源：

动作类型每回合数量常见用途
动作（Action）1次攻击、施法、疾走、撤离、推击、使用物品
附赠动作（Bonus Action）1次跳跃、潜行、副手攻击、快速施法、喝药水
移动（Movement）依种族标准9m/回合。可拆分使用。
反应（Reaction）1次/轮借机攻击、护盾术、羽落术、反击（战斗大师）

加速术/动作如潮 可额外获得1次动作。加速获得的额外动作仅能做1次武器攻击。

护甲等级（AC）​

AC 决定敌人需要投出多高才能命中你。命中公式：1d20 + 攻击加值 ≥ 目标AC

护甲类型AC 计算方式
无甲10 + 敏捷调整值（武僧/野蛮人有额外加值）
轻甲护甲基础值 + 敏捷调整值（敏捷全加）
中甲护甲基础值 + 敏捷调整值（敏捷最多+2）
重甲护甲基础值（敏捷不加成）

豁免检定（6类）​

豁免对应属性常见效果
力量豁免STR抵抗推击、擒抱、定身
敏捷豁免DEX躲避火球、陷阱、范围法术（最常见）
体质豁免CON抵抗毒素、疾病、即死效果、专注
智力豁免INT抵抗精神攻击、灵能
感知豁免WIS抵抗魅惑、恐惧、支配（最关键）
魅力豁免CHA抵抗放逐、异界盟誓

专注机制​

许多强力法术需要专注维持。核心规则：

  • 同一时间只能专注一个法术
  • 受到伤害时需通过体质豁免（DC=10 或 伤害值的一半，取较高者）
  • 专注豁免失败 → 法术立即中断
  • 陷入失能状态 → 专注自动中断
  • 战法大师专长、体质豁免熟练、战法师子职业可提升专注稳定性

休息机制​

休息类型恢复内容消耗
短休恢复50% HP上限的生命。邪术师恢复法术位。战士恢复动作如潮。补给品×0，每日2次
长休完全恢复HP与法术位。推进剧情、触发营地对话。补给品×40（战术家×80）

长休会推进剧情！ 某些限时任务可能在长休后失败。建议在安全时机进行长休。

地表与环境效应​

BG3 战场上的地表效果极其重要，利用好了能以一敌多。

地表类型效果触发方式
火焰地表每回合1d4火焰伤害油脂+火 / 炼金火
冰面需DC10敏捷豁免，失败倒地冰霜法术 / 水+冰
闪电水面带电水面造成额外电击伤害水+雷电
酸液站在上面被减AC 2点酸液瓶 / 酸液飞溅
油脂困难地形，DC10敏捷豁免否则倒地油脂瓶 / 油脂术
云雾重度遮蔽（致盲效果）雾凇云 / 黑暗术
荆棘困难地形 + 每回合穿刺伤害荆棘丛生

先攻（Initiative）​

BG3 中先攻使用 D4（而非桌游的D20），这使得先攻加值的权重极高。

先攻加值来源数值
敏捷调整值+0~+5
警觉专长（Alert）+5
装备加成部分装备提供

D4先攻意味着+5警觉几乎保证先手，这对荣誉模式极为重要。
